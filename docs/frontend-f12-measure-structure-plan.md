# F12 小节结构操作

## 已实现范围

F12 是五线谱工作区的中频结构编辑能力，不创建新的停靠组件。操作目标始终是一个明确的小节，第一版提供三个动作：

- 在当前小节前插入空小节。
- 在当前小节后插入空小节。
- 删除当前小节；乐谱只剩一个小节时禁用。

默认入口是谱面小节右键菜单，“编辑”导航菜单提供可发现入口。右键菜单显示“第 N 小节”，避免用户猜测操作目标。第一版不分配默认快捷键，保留跨平台快捷键空间。

## 数据与命令边界

Workbench 只把结构意图转换为已有 Core 命令：

- 插入调用 `core.measure.insert`。
- 删除调用 `core.measure.remove`。

插入的小节继承目标小节拍号，不继承弱起属性；每个 part 和 voice 都创建新的空内容及新 ID。一次插入或删除只提交一个 Core 命令，因此各占一个撤销步骤。删除会由 Core 同时移除该小节定义及各 part 对应内容，撤销恢复完整结构和原内容。

Host 在提交前处理两类可预期冲突：目标小节已经失效时返回 `editor.measure-stale`；删除最后一个小节时返回 `editor.measure-required`。这些是结构编辑反馈，不由组件自行复制校验规则。

## 光标与选择

结构操作完成后清除事件或范围选择：

- 插入后，光标定位到新小节起点。
- 删除后，优先定位到原索引处的下一小节；删除末尾小节时定位到前一小节。
- 右键菜单关闭后焦点回到谱面，后续键盘输入继续由统一命令路由和编辑状态机处理。

## 视觉与布局

右键菜单使用紧凑浮层，不在每个小节上放常驻按钮。删除项仅使用危险色文字和轻悬停底色；最后一个小节时保留禁用项，让规则可见。菜单会根据视口边界调整位置，并支持点击外部、滚动、缩放窗口和 `Esc` 关闭，以及方向键、`Home`、`End` 导航。

## 后续范围

- 批量插入或删除多个小节。
- 跨小节范围选择后的结构操作。
- 拍号变化、调号变化和谱号变化的专用上下文流程。
- 复杂多谱表视图开放后，对多 part、多 voice 结构编辑做端到端界面验收。
