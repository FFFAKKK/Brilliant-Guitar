## 本轮依据与目标

- 本会话用户最新要求：先列出全部拟做组件及其小功能，逐项审核后再实现。
- 不创建 Trellis 任务；先完成基础五线谱编辑闭环，再处理美术与动画。
- 工作台不显示产品名称。文件功能归入导航菜单。
- 自定义的重点是未来用户能编写组件或插件；本期只使用简单主题变量，不建设主题编辑器。
- 工作台、谱面、领域能力和内核接入保持边界，不恢复被否决的旧界面。

验收闭环：新建／打开 → 定位 → 连续输入 → 修改／删除 → 撤销／重做 → 保存 → 重新打开继续编辑。

建议首个切片使用单文档、单谱表、单声部的基础高音谱表旋律编辑。初始 4/4、单小节，可在新建对话框中增加小节。多谱表、多声部、和弦、复杂节奏及其他谱号暂不纳入首片。以上为控制首片范围的建议，需要审核，不是用户已有决定，也不是内核能力上限。

## C01 工作台容器

最新布局边界（用户纠正后）：先实现组件独立装配、宿主传入尺寸、内容自适应和独立缩放等基础能力；用户布局编辑后置。组件化不要求显示标题栏或套卡片，当前五线谱不显示“五线谱／单声部”标题行，工作区为透明布局层，仅谱面拥有白色表面。尺寸输入弹窗和面板按钮已移除，拖拽入口默认不启用；未来布局编辑采用鼠标边缘拖拽，不恢复数值弹窗方案。

左右停靠区采用覆盖层：中央工作区始终占满中间舞台，左右区域只覆盖其边缘。开启、关闭或拖拽左右停靠区不得改变中央工作区尺寸，也不得触发 A4 谱面重新适配或位移。上、下停靠区仍作为明确的横向布局带参与高度分配。2026-09-15 已在 1440×900 浏览器视口验证左右开关和两侧拖拽，工作区与谱面边界保持不变。

首次进入工作台时四个停靠区均默认展开，让用户立即看见已经装配的能力；用户主动收起后的选择可以保存，“恢复默认布局”重新展开全部停靠区。空区域不会因为当前暂未装配组件而自行关闭。

小功能：

1. 导航区域：固定在顶部，不随谱面滚动。
2. 内容区域：首次进入空工作区自动装配默认四小节空白谱；已有文档时继续恢复该文档。
3. 属性区域：提供固定侧边接入位；没有组件时不占空间。
4. 工具装配：通过组件接口放入输入、编辑、视图工具，不在外壳里实现音乐功能。
5. 空间适配：窗口缩小时保持菜单可达、内容可滚动，避免控件遮住谱面。

不拥有音乐文档、编辑历史或乐器规则。属性宽度调整可作为小型布局能力后续接入，不影响首个音乐闭环。

## C03 新建乐谱对话框

小功能：

1. 作品标题：可填写；留空使用“未命名乐谱”。这是作品信息，不是工作台品牌。
2. 初始小节数：默认四小节，可设定合法的小节数量。
3. 基础格式说明：明确展示首片支持的高音谱表、单声部、4/4，不伪装为任意模板选择器。
4. 创建／取消：创建成功才切换当前文档；取消不改变当前文档。
5. 校验反馈：输入不合法时在相关字段旁提示，不丢失已填写内容。

当前实现：标题选填、最多 120 字符；小节数默认 4，限制 1–128；真实 Native 创建单谱表、单声部、高音谱号、4/4 的空白乐谱。初始化不进入用户撤销历史。表单校验、忙碌状态、错误重试、取消焦点返回已经接入。

由于 C09 保存尚未开放，已有作品时先采用明确勾选放弃的替换确认；后续接入 C09 的保存／不保存／取消流程。当前只保存进程内会话，不能视为文件保存。创建成功后由 C04 显示空白五线谱。首片不提供乐器商店、模板库或高级编制设置。

## C04 五线谱编辑视图

当前进展：真实快照 → 只读显示投影 → 独立排版 → 可替换 SVG 绘图适配。已显示五线、高音谱号、实际拍号、小节线、编号、单音、休止、单附点、基础变音和连梁，支持随工作区宽度换行与长谱面滚动。布局不修改音乐文档或历史；遇到本轮尚未支持的音乐内容明确提示。下列清单仍是 C04 最终目标，不能将基础显示完成等同于编辑视图全部完成。

小功能：

1. 基础绘谱：五线、谱号、拍号、小节线、音符、休止、附点、基础升降还原符号及必要连梁。
2. 位置映射：将鼠标位置映射到谱表、小节、节拍与音高，不仅绘制一张图片。
3. 选择：选择单个音符／休止，扩展连续范围选择；多选对象视觉明确。
4. 输入光标：单独表达下一次输入的位置，不与当前选中对象混为一个状态。
5. 连续输入：键盘输入后按时值前进，无需每个音符额外确认；小节已满时前进到下一小节。
6. 更新：读取内核提交后的文档刷新；拒绝编辑时保留原谱面与操作位置。
7. 空白与留白：未填写位置可以有派生的排版占位，但不能为了显示而偷偷写入音乐数据。
8. 滚动定位：让当前编辑位置保持可见，缩放后仍能准确命中对象。

谱面容器不依赖某个绘谱库的内部对象；底层排版／绘制和编辑命令之间有明确适配边界。

## C05 音符输入组件

2026-09-13：用户已同意“音名 → 组号 → 落谱”，当前键盘输入已切换为此规则。A–G 只生成 UI 草稿并在短光标旁显示 `A_`，合法组号 2–6 完成后才提交一个音符；按当前时值前进，一次输入只占一个撤销步骤。顶排数字与数字小键盘均用于组号，时值继续使用工具选择。

待组号阶段：另一音名替换草稿，Backspace 取消草稿，Esc 清空并退出。非法数字保留草稿并提示；数字先于音名时不落谱；按键自动重复不产生提交。R 取消草稿并直接写入休止，鼠标定位、历史操作和更换文档取消草稿；时值和变音调整可保留草稿，提交时使用当前设置。没有超时自动填组号。独立的 `advancePitchEntry` 负责键盘语法，输入会话负责提交队列，绘图适配只显示草稿，不创建另一份音乐文档。

官方参考：
- [MuseScore 默认输入](https://handbook.musescore.org/basics/entering-notes-and-rests)：先时值后 A–G，默认选邻近八度，数字快捷键用于时值。
- [MuseScore 先音高后时值](https://handbook.musescore.org/en_gb/basics/input-by-duration-mode)：音高预览后由时值键确认输入。
- [Dorico 先音高后时值](https://www.steinberg.help/r/dorico-elements/6.1/en/dorico/topics/write_mode/write_mode_note_input/write_mode_note_input_inputting_notes_pitch_before_duration_t.html)：支持预选音高与影子音头，默认仍为先时值后音高。

当前插入标记已从跨谱表长线改为居中的短细线（100% 下高 16px、线宽 1.5px），仅表达时间位置。`A_` 草稿提示已实现；尚未绘制待输入的音高预览音头。

当前切片：独立输入工具装配在谱面下方的灰色工作区中，支持全至十六分时值、单附点、自然／升／降音、C2–B6。音名与组号配对输入，R 休止，Esc 退出；单击小节定位到内容末尾，双击按鼠标纵向音高追加。恰好写满后进入下一小节；容量不足拒绝并停止后续队列，不覆盖已有事件。只实现末尾追加，不宣称任意拍插入或已有事件修改已完成。

小功能：

1. 输入模式：进入／退出连续输入，明确当前状态。
2. 音符／休止：选择下一次写入的内容类型。
3. 时值选择：全音符、二分、四分、八分、十六分；首片支持单附点。
4. 音高输入：键盘输入音名，支持八度与基础半音调整；鼠标定位也能输入。
5. 当前输入设置：明确显示时值、附点、变音和输入位置。
6. 焦点保持：鼠标调整输入参数后能继续键盘写谱，不误把下一次输入交给按钮或菜单。

边界：该组件设置“接下来写什么”。修改已选中音符由 C07 或编辑命令完成，不因切换输入时值而隐式改动选区。

## C06 快捷编辑组件

2026-09-13 新增切片：`useScoreSelection` 独立管理所选事件 ID；`SelectionControls` 独立呈现删除操作与说明。单击音符／休止符选择并退出输入，←→ 切换，Esc 清除；Delete、按钮和编辑菜单使用同一删除入口。音符删除后改为同 ID、等时值休止符，后面的事件不前移；使用公开 Core 批事务实现，一次撤销还原原音符。末尾休止可移除，中间休止保持以保留节拍。输入草稿与选择分开，进入输入清除选择，选择音符取消输入草稿。多选、剪贴、小节增删尚未实现；属性编辑已由 C07 接入。

当前切片：`HistoryControls` 独立组件与全局编辑菜单共用输入会话的命令入口，读取真实 Native undoDepth／redoDepth；谱面聚焦时 Ctrl+Z／Ctrl+Shift+Z 生效。单事件选择和删除已接入；剪贴和小节操作尚未实现。

2026-09-15：编辑历史采用无标题的双图标紧凑控制组，默认位于上方停靠区。无可用历史时降低层级，悬停显示快捷键和实际步数；按钮、菜单和快捷键共用同一分发入口，成功触发后对应图标播放短反馈动画。动画遵守全局动画开关。已在本地浏览器验证输入后撤销可用、撤销后重做可用以及 Ctrl+Z／Ctrl+Shift+Z 的状态与动画绑定。

小功能：

1. 撤销／重做：使用内核统一历史，正确显示是否可执行。
2. 删除内容：删除选中的音符／休止，其他事件不隐式前移；空出的时间由谱面明确表达。
3. 复制／粘贴：首片支持应用内基础音符／休止片段，保留相对时序及基础属性。
4. 剪切：先成功建立剪贴片段再删除；复制失败不能导致原内容丢失。
5. 小节操作：在当前小节后添加小节；删除当前小节时清楚表达结构性后果，整次操作可撤销。
6. 快捷入口一致：菜单、按钮和快捷键走同一操作逻辑。

复制粘贴是应用层需要组织的能力，不能因内核支持基本命令就宣称已完成。首片不支持跨软件剪贴格式、任意插件对象或复杂范围重排。

## C07 属性侧边栏

2026-09-13 当前切片：无选择提示、音符／休止属性、小节与拍位、作品标题、应用／重置、错误反馈与撤销重做已接入。音高字段合并为紧凑一行，时值与附点共用一行，保持谱面为主要区域。桌面固定右侧并可收起；不超过 640px 的窗口默认收起，通过视图菜单以抽屉展开，关闭后恢复谱面空间。这是本轮实现方案，仍待用户体验审核。

字段草稿不直接改写乐谱；一次应用经公开 Core 批事务修改，保留事件标识并产生一个历史步骤。缩短会补齐休止，延长只能使用相邻休止或尾部空白，后续音符拍位保持不变；时值冲突整次拒绝，保留待修正字段。支持用于精确补隙的无附点三十二分休止，输入工具仍保持全至十六分音符范围。标题独立提交；修改事件属性不会清除未应用的标题草稿。多选仍未接入。

组件边界：`ScoreInspector` 负责字段草稿，`InspectorSlot` 只负责固定栏／抽屉切换，时值与变音字段和 C05 共用；宿主准备命令并统一提交到 Native 历史。没有主题编辑器、布局编辑入口、播放或 MIDI 功能。

小功能：

1. 无选择状态：显示文档基础信息，或简短提示选择对象，不出现假属性。
2. 音符属性：音高、时值、附点和基础变音。
3. 休止属性：时值与附点，不显示不适用的音高字段。
4. 位置说明：显示归属小节与节拍，首片只读，不添加隐式移动操作。
5. 多选状态：显示选中数量；首片复杂批量属性修改不开放，避免只修改其中一个对象。
6. 文档属性：在明确的“乐谱”分区修改作品标题，不依赖取消选区的隐含操作。
7. 修改反馈：字段形成草稿，显式应用后提交；失败说明原因，保留原谱面和待修正字段，重置可恢复已提交值。

固定侧边，允许收起。字段复用基础控件，与 C05 可复用时值选择器，但两者操作对象明确不同。首片不显示力度、音色、弦品或技巧等尚未接入的业务。

## C08 视图控制组件

小功能：

1. 放大／缩小：调整显示比例，不修改音乐文档。
2. 比例显示与 100%：显示真实比例，可恢复标准比例。
3. 适合宽度：按当前可用工作区计算；属性栏显隐后重新计算。
4. 回到编辑位置：找回离开视口的输入光标／编辑目标。

不做打印排版、自由拖拽谱面元素、纸张设置和多种阅读模式。缩放与滚动不进入音乐撤销历史。

## C09 文件交互与确认组件

小功能：

1. 打开文件：调用浏览器／宿主文件选择能力；加载、解析、校验成功后才替换当前文档，同一文档重开也会重置编辑光标和选区。
2. 保存／另存为：浏览器预览下载 `.bgp.json` 项目文件，并按文档 ID 和精确版本记录检查点；另存为只改变文件名，不擅自修改作品标题。
3. 谱面导出：五线谱导出独立 SVG；文件内嵌 Bravura 与 Academico 字体并保留根级绘制样式，脱离工作台后仍能正确显示谱号、拍号、音符和休止符。导出 SVG 不改变项目保存状态。
4. 未保存确认：新建或打开其他乐谱前提供“保存并继续／放弃修改／取消”。保存失败时不继续丢弃当前文档。
5. 加载失败：指出无法打开的原因，保留当前作品。
6. 保存失败：保留未保存状态，允许重试或另存，不显示成功。
7. 不支持的内容：明确拒绝不支持的编辑或打开方式，不静默丢弃数据后保存。
8. 浏览器／宿主关闭：当前使用 `beforeunload` 离开保护；不能承诺页面被强制结束时仍可完成异步保存。

这是交互组件与宿主服务的组合，不是独立文件管理面板。浏览器预览中的“保存”表示导出当前版本的项目文件，不能覆盖此前下载到桌面的同一文件；桌面应用接入后应由 Native 文件适配器提供真实路径和原文件覆盖，界面与文档命令不需要重做。检查点元数据可以放在会话存储中，但乐谱正文不能以浏览器缓存冒充文件保存。首片不承诺自动保存、崩溃恢复和跨重启撤销历史。

## C10 状态与操作反馈组件

小功能：

1. 文档状态：无文档、未保存、保存中、已保存、保存失败均有准确来源。
2. 编辑状态：输入／选择模式、当前位置、选中数量。
3. 操作反馈：区分成功修改、无需修改、被拒绝；失败时保留足够时间查看原因。
4. 忙碌状态：打开／保存／提交进行中阻止重复危险操作，同时不让界面失去响应。

建议采用紧凑状态区；它是否固定在底部是待审核的布局建议，不是已确认要求。只显示当前真实存在的状态，不增加常驻日志台或调试面板。

## 共用子组件与内部机制

这些不会变成额外的独立面板，也没有单独的产品入口。

| 子组件／机制 | 用途 |
|---|---|
| 按钮、图标按钮 | 普通、选中、禁用、忙碌、键盘焦点等一致状态 |
| 选项组、选择器 | 时值、输入类型等单选；对外提供值和变更事件 |
| 文本／数值字段 | 标题、小节数、音高等字段的输入与校验提示 |
| 菜单、对话框、确认框 | 浮层定位、键盘操作、焦点进入与返回 |
| 面板容器 | 标题、内容、显隐与尺寸约束；不处理音乐业务 |
| 字段错误与状态提示 | 复用反馈方式，不复制一套通知逻辑 |
| 编辑会话 | 选区、输入目标、输入设置与视口的统一来源 |
| 命令连接 | 菜单、工具、属性和快捷键连接到内核公开接口 |
| 内核会话适配 | 公开读取、提交、订阅、撤销重做；不导入私有实现 |
| 宿主文件服务 | 文件选择、读取与可靠写入；成功后再通知保存检查点 |
| 简单主题变量 | 统一颜色、字体、边界、圆角与间距，无用户主题编辑器 |

## 第一片建议采用的编辑规则

以下需要与组件一起审核，防止控件有了而行为含糊。

1. 首片单谱表单声部；默认 4/4，但时值可选择和修改，不能停留在固定时值演示。
2. 输入参数影响后续输入；选中内容的属性通过显式修改生效。
3. 新输入与已有内容冲突、超出小节容量时明确拒绝；不静默覆盖，不自动移动后续音符。
4. 跨小节自动拆分、延音线、复杂节奏、插入式挤压排布后续单独设计。
5. 删除音符与删除整个小节是不同命令。前者留出时间，后者修改结构；两者均可撤销。
6. 复制粘贴首片限定应用内基础内容，不悄悄遗漏插件属性；不支持的片段应拒绝。
7. 文件写入成功时按实际保存版本更新状态；写入期间发生的新编辑不能误标为已保存。

## 建议实施顺序

1. C03 + C04 最小显示 + C09 打开／保存 + 内核会话适配：先证明真实文档能创建、显示和保存重开。
2. C05 + C04 输入／选择 + C06 撤销重做／删除 + C07：完成基本编辑。
3. C06 剪贴／小节操作 + C08 + C10 + C09 离开保护：补齐日常操作和失败路径。
4. 在统一闭环场景下验收后，再安排视觉精修及后续扩展。

每一步保持可运行；菜单和状态随实际能力启用，未完成能力保持不可执行。不得将组件数量或静态渲染成功等同于闭环完成。
