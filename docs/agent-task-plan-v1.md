## 当前工作：c2b 工具拒绝反馈（首发实现）

目标：预算或输入上限导致的工具组阻断，能够通过结构化拒绝反馈让支持的Agent做一次缩小/替代/解释决策；不把拒绝伪装为成功工具结果，不无限重试。

- 权威合同：[M3.2c2b 拒绝反馈与受控恢复合同](./agent-m3.2c2b-rejection-feedback-contract-v1.md)。
- 当前推荐范围：Controller 公共 `toolFeedbackRejections`；第一方 Pi v1 映射为 `isError=true` 的工具结果；External Agent Protocol v1 保持严格兼容并沿用现有失败路径。
- 只恢复 `blocked/input-budget` 和 `blocked/input-limit`；unsupported 首发沿用本地失败，contract-error、取消、迟到和执行不一致不续接。
- 单次拒绝最多一次模型恢复决策；再次请求同一组直接结束。每次替代调用重新通过授权、c2a 预检、执行和最终预算。
- 已实现公共拒绝反馈 DTO、严格校验和深冻结；拒绝不会伪装成成功工具结果或工具活动。
- 已实现拒绝运行事件和 Pi v1 一次恢复；External Agent v1 不扩 wire，能力为 `none`。
