## 6. 保持的架构决策

- 复用 Pi 组件，第一方 Pi 是默认的可替换 Agent 插件；不另造第二个 Controller。
- 模型供应商、外部 Agent 插件与 MCP 工具连接分别处理。
- 通用上下文与能力合同不依赖 Pi；插件负责各自协议投影，宿主提供实际资源和工具。
- 完整聊天记录、本轮模型输入和执行 Run 分开管理；恢复聊天不自动重放工具。
- 独立宿主与软件宿主共享同一运行内核，乐谱版本和 ChangeSet 规则保留在业务适配层。
