# F11 范围选择与剪贴编辑

## 已实现范围

F11 是五线谱工作区的交互能力，不创建新的停靠组件。第一版限定在单谱表、单声部、单小节内的连续事件，事件可以是音符或休止符。

- `Shift + 单击`：以当前事件为锚点，扩展到点击事件。
- `Shift + ← / →`：从固定锚点扩展或收缩范围。
- `Esc`：先清除范围，再按一次退出单事件选择。
- `Ctrl / ⌘ + C`：复制当前范围；没有范围时复制当前事件。
- `Ctrl / ⌘ + X`：复制后原子删除范围。
- `Ctrl / ⌘ + V`：在当前编辑位置或当前事件之后插入，不覆盖已有内容。

## 数据与命令边界

剪贴内容使用严格校验的 `ScoreClipboardFragmentV1`，只携带事件顺序、时值、休止或单音内容、书写音高与变音。浏览器剪贴板不可用、权限被拒绝或含有其他文本时，工作台回退到当前会话内存剪贴板。

范围删除复用 Core 的 `core.range.delete`。粘贴在 Host 中生成新的事件与音符 ID，并通过一次 `core.transaction.batch` 原子提交，因此剪切和粘贴都各占一个撤销步骤。粘贴可能造成超拍，但不会被 Workbench 预先拒绝，仍由 Core 规则诊断显示轻量提示。

## 视觉规则

范围选择使用独立 SVG 范围带。横向边界来自所选事件的真实雕刻几何，纵向边界固定依附五线谱，不随高低音跨度变成巨大矩形。单事件选择框、输入光标、悬停预览和播放头继续保持独立语义。
