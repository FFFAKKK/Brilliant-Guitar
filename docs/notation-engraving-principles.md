# 谱面组件的记谱与排版依据

确认日期：2026-09-16。

用户要求：五线谱、六线谱和其他谱面组件，先核对适用的记谱规范和成熟制谱惯例，再设计和实现。记谱正确性优先于美化；没有统一规定的部分明确作为设计选择，不称为国际标准。验收同时检查实际符号位置与真实界面。

## 依据及适用范围

- [SMuFL 1.4](https://www.w3.org/2021/03/smufl14/)：音乐符号映射、音乐字体的度量与定位。它是 W3C Music Notation Community Group 的报告，不是 W3C 正式标准，也不规定整张谱面的唯一布局。
- [SMuFL 字形度量与定位](https://www.w3.org/2021/03/smufl14/specification/scoring-metrics-glyph-registration.html)：一 em 对应四个谱间距；谱号按所指音高定位；拍号数字高两个谱间距并围绕基线居中；全休止符从字体基线下悬。
- [SMuFL 休止符](https://www.w3.org/2021/03/smufl14/tables/rests.html)：全休止符下悬，二分休止符上托，二者不可使用相同的音高坐标定位。
- [LilyPond 全小节休止符](https://lilypond.org/doc/v2.24/Documentation/notation/writing-rests)：单声部的全小节休止符默认位于第四线下面，水平居中；根据拍号选择全休止或倍全休止符。
- [LilyPond 谱表大小](https://lilypond.org/doc/v2.24/Documentation/notation/setting-the-staff-size)：常规分谱的参考谱高为 20 pt / 7.03 mm；不同编制和用途可以采用不同尺寸。

## 当前五线谱

- A4 竖向，纸面逻辑单位与屏幕像素分离；每毫米对应 10/3 个纸面单位。
- 采用 7.03 mm 参考谱高。符号、谱线、附点、变音符号、连梁在同一绘图坐标系内缩放，不通过组件外的 CSS 分别修补符号位置。
- VexFlow 适配层使用 `r/4` 休止键，让引擎按时值决定默认谱线位置；不能用 `b/4` 固定所有休止符。
- 编辑工作台中的空小节保持视觉空白，不绘制占位休止符，也不写入 Core。每个基本拍仍有纯 UI 光标锚点；用户在后续空拍真正输入时，宿主才以一次原子编辑补齐必要的真实休止符。真实休止符始终读取真实文档事件。
- 连梁使用对应拍号的引擎默认分组；6/8、9/8 按附点四分拍分组。非对称拍子的默认分组是排版预设，后续可按音乐语义扩展，不是唯一标准答案。
- 空的起始小节宽 18 个谱间距，后续空小节宽 11 个谱间距；这是当前的紧凑布局选择。非空小节按事件密度、时值、附点和变音符号保留空间，换行、换页不修改文档。
- 默认按中央区域的可用宽、高等比适配竖向 A4，顶部齐平、水平居中，左右保留适量空隙。不设置强制最小像素比例；纸张与全部音乐符号使用同一显示比例。独立缩放工具后续单独审核，不在本轮装配。
- 调整停靠区尺寸时重新适配纸张，清除横向偏移；已处于页首时保持页首，不把第一行移到视口外。长谱面的多页内容可纵向滚动、中键平移；滚动和尺寸变化均不修改音乐文档。
- 公共组件宿主只提供生命周期、尺寸和焦点等逻辑。纸面、排版及导航交互由谱面组件及其独立逻辑模块负责。

## 音符输入组件

- 使用 SMuFL 单个带符干音符字形显示全至十六分时值，不能用两个连梁八分音符代替一个十六分音符。休止符、附点与变音按钮使用对应字形。参考：[Individual notes](https://www.w3.org/2021/03/smufl14/tables/individual-notes.html)。
- 工具中的符号不是谱表中的音高定位：测量本地 Bravura 实际墨迹边界后，在独立符号框中居中，不修改五线谱内的字体基线或谱线定位。
- 音符与附点采用同一字体基线；完整音名中的升降号仍用 Bravura，并以带留白的实际墨迹视口等比适配，不能因通用图标框的空白而缩得过小。选中三十二分休止时显示真实字形，输入范围仍为全至十六分。
- 音符控制有空、升、降、还原四种状态，但只呈现 `♭`、`♮`、`♯` 三个按钮；三个按钮全部未选中表示空，再次点击当前按钮也回到空。音名中间字段按当前记号状态显示，空状态不绘制字符。
- `WrittenPitch { step, alter, octave }` 整体是持久化的、保留同音异名拼写的绝对书写音高；其中 `alter` 是相对该音名字母自然音的半音变化量，不是“是否绘制变音记号”的开关。实际发声音高由 `WrittenPitch` 与 Part 移调关系派生，不保存第二份可漂移事实。变音记号则由记谱规则层结合调号与小节内上下文计算：状态未变化时为空，变为升或降时显示对应符号，回到自然音时显示还原号；当前小节开始暂以 C 大调／无调号为初始状态。
- 输入概览是当前参数与最近成功输入音高的预览；选择概览从当前只读投影按事件 ID 解析真实属性。组号未完成时显示下划线，不借用之前的组号；休止符不显示虚构音高。选择后的修改复用现有 Native 属性／删除动作，公共组件宿主不持有音乐编辑逻辑。
- 音名下方分数表示整个当前小节的占比，不是音符名义上占全音符的比例。复用精确时值单位与小节容量计算并约分，附点已包含在数值中；例如 4/4 附点二分为 `3/4`，6/8 附点四分为 `1/2`。实际音符字形仍保留附点。占比是本项目的界面展示选择，不称为国际记谱标准。
- 呈现控件、输入会话、纯键盘语法和 Native 提交分别分层。鼠标加减与键盘加减共用时值逻辑；草稿与参数不修改音乐文档。
- 已核查 14 个本地实际字形都存在且完整落在居中的 48 单位符号框内。字形核查不代表浏览器布局、鼠标命中和焦点交互已完成验收。

## 后续谱面与验收

### 自动记谱规则边界

- 调号属于谱表／小节属性，传统调号以五度圈位置表示；进入新小节或发生调号变化时，变音状态必须从新的调号上下文重新建立。
- 临时变音、必要还原、跨小节重置、调号取消和中途换调由独立的记谱规则层计算。音符控制只表达用户意图，VexFlow 适配层只消费计算结果，不各自复制规则。
- 以后支持调内级数、简谱数字或其他快捷输入时，先由输入适配器结合当前调号转换成规范的书写音高，再进入同一编辑命令和排谱流程；不会另外维护一份只能用于某种输入法的乐谱数据。
- 和弦、多声部、跨谱表、同音异名、提示性／编辑性变音及微分音需要分别核对作用域和导入导出表达，不能从当前单声部算法直接类推。

六线谱、其他谱表应分别核对线数、弦与音高映射、谱号／数字、节奏和连梁表达、特殊技法符号及字体支持。它们复用纸张与视口逻辑，不直接套用五线谱的垂直定位规则。

检查至少覆盖：单小节空白谱、全／二分／四分休止符、附点与升降还原、谱表内与加线音符、简单拍与复合拍、密集内容、长谱面的换行换页，以及窗口缩放和平移。几何测试不代替浏览器视觉和交互验收。

截至 2026-09-16，工作台 95 项测试及生产构建通过。浏览器已实际核查：初始单小节没有占位休止符；方向键可依次选择 4/4 的四个空拍；在第三拍输入会补齐前两拍的真实休止符并保持一次撤销历史；浏览器控制台无错误或警告。
