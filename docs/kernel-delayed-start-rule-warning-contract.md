# 延迟声部起点规则警告合同

状态：2026-09-17 已实施。

当声部的非负规范起点晚于所属小节的标称终点时，文档仍然结构完整。内核允许创建、导入、事务提交、撤销、重做、保存和重新打开该状态，并通过规则警告页返回 `rule.sequence-start-after-measure`。

V1 警告沿用现有时间警告字段：

- `nominalDuration`：拍号与弱起共同决定的小节标称长度；
- `actualDuration`：该声部的实际起点；
- `overflow`：实际起点减去标称长度；
- `partId`、`measureId`、`voiceId`：稳定定位警告对象；
- 警告页上的 `documentId` 与 `documentVersion`：防止宿主把旧警告贴到新版本。

同一延迟起点也会使声部终点超过小节长度。为避免一个根因产生两个节拍计数，内核对该声部优先返回延迟起点警告；起点仍在小节内、仅尾部超出时继续返回 `rule.sequence-exceeds-measure`。

以下情况仍是阻断错误：负起点、非规范分数、时间算术溢出、无效拍号、缺失引用、重复身份、陈旧版本和非原子事务。K1 功能配置仍可把非零起点分类为 `unsupported.sequence-start`；这是当前视图或功能集的能力限制，不会把文档重新判为损坏。
