# 组件清单与空白工作台规范

日期：2026-09-13。
状态：供用户讨论的基础草案，尚未确认具体尺寸、色值及默认位置；不作为已批准视觉稿或已实现能力。

## 当前设计对象

用户选择的方向：通过多个组件组成工作台，部分固定，部分可活动；学习成熟产品的组织思路，建立自己的视觉语言。上一轮任何整屏候选都没有被选为实现目标。

本轮先定义组件职责、最小外观、布局行为与空白外壳。这里的空白工作台是装配基础，不要求最终用户从空白自行搭建。实际产品提供默认可用布局。

本次只编辑设计文档；不修改现有应用、内核或用户乐谱，不进入 Trellis 任务流程。

## 一、产品组件清单

| 组件 | 最小内容 | 默认位置/出现时机 | 可调整行为 | 阶段 |
|---|---|---|---|---|
| 导航与文档栏 | 产品名、文件/编辑/视图入口、文档名、保存状态、保存入口 | 顶部固定 | 自适应缩减文档名；核心入口不被拖走 | 基础 |
| 谱面工作区 | 文档视图容器、滚动、缩放、焦点及共享选择的承载 | 中央，自动占满余下空间 | 随周边组件伸缩；未来支持谱面组合 | 基础 |
| 基础记谱工具条 | 写入/选择、时值、休止、附点、更多 | 有适用文档时默认置于导航下 | 顶部/底部停靠、调整组顺序、收起；收起后保留恢复入口 | 第一组功能组件 |
| 状态栏 | 当前编辑状态、位置、简短提示、缩放 | 底部固定 | 低优先级信息可随宽度收缩 | 基础 |
| 上下文菜单/小工具条 | 当前对象最常用动作 | 右键或明确调用时靠近目标出现 | 临时；可关闭，避免遮挡目标与屏幕边界 | 第一组功能组件 |
| 属性面板 | 当前对象的补充属性 | 用户主动打开，默认右侧 | 左/右停靠、调宽、关闭；关闭不清空选区 | 后续组合验证 |
| 技巧工具组件 | 已具备能力提供的技巧动作 | 对应插件可用且用户选择显示时出现 | 工具条/面板/上下文动作共用同一动作来源 | 吉他等扩展阶段 |
| 播放控制组件 | 播放、位置及相关基础控制 | 播放能力接通后加入 | 预留紧凑工具条或底部停靠形式 | 后续，不在空白外壳占位 |

文件对话框、设置视图、错误提示属于上述流程使用的通用交互组件，不作为可随意拖放的常驻面板。初版按单文档组织，仅在布局合同预留将来的多文档区域，不显示无效标签。

## 二、通用视觉组件

先建立少量可重复组合的控件，而不是给每个功能独立画一套样式：

- 文本按钮、图标按钮、分段选择：统一尺寸与默认/悬停/按下/选中/禁用/焦点状态。
- 工具组：标签、小符号、分隔线与溢出入口；名称说明组的用途，避免每个符号都配大块说明。
- 提示、菜单、轻量弹出控件：统一键盘导航、关闭和定位规则。
- 面板框架：可选标题、收起/关闭、拖动手柄及尺寸限制，内容由功能模块提供。
- 分隔拖柄：调整相邻停靠区尺寸。
- 表单字段、对话框、行内反馈：服务文件、设置和错误恢复；不承担逐音提交。

谱面中的音符、谱线和音乐排版由专业绘谱模块生成，不当作通用按钮组件的样式变体。

## 三、空白工作台的建议样式

这是一组用于首轮排布验证的默认值，不是永久设计系统版本。

| 项目 | 默认建议 |
|---|---|
| 风格 | 中性浅色、紧凑、平面化；通过对齐、留白和细分隔建立层级 |
| 主背景 | `#F5F6F8`；工作台铺满应用窗口 |
| 固定栏/面板表面 | `#FFFFFF`，以 `#E2E5EB` 的 1px 分隔线区分 |
| 文字 | 主要 `#252A34`，次要 `#626B7A`；正文/控件 14px，辅助信息 12px |
| 强调 | 暂用低饱和蓝 `#5269C7`，仅用于选择、焦点和少量关键状态；后续可替换主题 |
| 导航栏 | 44px 高；品牌采用普通字标，文档名不作大标题 |
| 工具条 | 单行36px高；常用符号18–20px，按钮目标28–32px；不采用时值卡片阵列 |
| 状态栏 | 24px 高，信息单行，不扩展为大片说明区 |
| 间距 | 以4px为基本步进；组内4–8px，组间12–16px |
| 圆角/阴影 | 控件2–4px；普通工具组不加卡片边框；仅临时浮层使用轻微阴影 |
| 中央工作区 | 自动填满剩余空间，普通工具不作为卡片铺在中央 |

完整空白外壳只呈现顶部导航、中央底面和底部状态栏。未使用的左右/底部停靠区不占宽度，不显示虚线插槽、“插件区域”等技术占位文案。需要引导时在中央保留一行轻量的新建/打开入口，不使用大面积欢迎卡片。

装入记谱工具后，在导航下增加紧凑工具行；装入五线谱后，由视图在中央绘制自己的内容。谱面是否采用纸张边界或连续画布是视图设置，不能与整个工作台的底面样式绑定。

## 四、活动组件的规则

### 固定与可停靠

导航栏和状态栏固定。谱面工作区保留中央位置，尺寸随布局改变。工具条默认允许上/下停靠，普通属性面板允许左/右停靠；不是每个组件都能进入任意区域。

拖动只从明确手柄开始，不抢占工具按钮点击、文字选择和谱面框选。拖动时才显示放置目标，释放前展示结果；Esc 取消。提供“移动到顶部/底部/左侧/右侧”菜单作为无需拖动的替代路径。

小工具条悬浮作为可选能力预留。建议第一轮先验证停靠/收起/恢复；悬浮需要同时解决窗口变小、遮挡、丢失位置和焦点问题，再开放给用户。独立系统窗口与任意层叠面板不在首轮范围。

### 默认布局

- 顶部：导航与文档栏。
- 导航下方：基础记谱工具条，仅在适用文档存在时显示。
- 中央：五线谱工作区。
- 底部：状态栏。
- 左右：默认收起，不预留空栏；属性和技巧由用户主动打开。
- 谱面附近：上下文菜单按需出现，不能每选一个音符就自动弹出大面板。

### 布局记忆与恢复

位置、顺序、尺寸和可见性可自动记忆，提供“恢复默认布局”。恢复仅改变工作台配置，不删除乐谱、不修改历史、不重置音符输入值。配置带版本；未知组件或不兼容位置不会阻止工作台启动。暂缺的可选组件保留其配置，恢复可用后再按合法位置装配。

窗口变窄时优先压缩次要信息并折叠可选面板；保留文件、当前输入状态和时值组的明确入口。工具组不得无限换行变成厚工具墙，谱面允许自身滚动。精确最小宽度与断点在组件排布原型中验证。

## 五、分层合同

| 层 | 负责 | 边界 |
|---|---|---|
| 视觉基础 | 语义样式、控件、状态与密度 | 不知道乐谱和内核 |
| 布局外壳 | 停靠、可见性、尺寸、装配、焦点协调 | 不实现某种乐器业务 |
| 功能与交互 | 输入模式、临时时值、动作定义、上下文 | 经公开能力协作；不复制内核文档/历史 |
| 谱面适配 | 绘制、命中、语义位置与屏幕坐标映射 | 绘谱库对象留在模块内部 |
| 宿主适配 | 公开内核接口、版本化提交、读回、历史、文件 | 不依赖某个组件的布局或主题 |

组件贡献至少说明稳定身份、所需能力、允许位置、尺寸约束、可见性条件及挂载/更新/销毁责任。对未知能力或重复身份给出明确结果。每个按钮不必成为独立插件；公开注册仅用于真实的扩充/替换边界。

时值工具条、快捷键、上下文菜单共用同一动作；更换位置不会改变语义。任何插件都不能导入内核实现、直接写文档或建立第二套撤销历史。

状态分开：音乐事实与历史归内核；光标/选择/临时输入归编辑会话；布局/主题/显示偏好归工作台配置。

## 六、接下来的顺序

1. 与用户收口组件清单、固定/活动关系和空白外壳风格。
2. 单独展示空白外壳，以及紧凑工具条/临时菜单/面板框架的组件样式，不把完整大界面当唯一设计对象。
3. 用同一组组件拼出默认工作台，验证正常与窄窗口、收起与展开状态。

本轮不决定最终强调色、精确快捷键映射、跨小节时值重排策略，也不因为组件清单存在就承诺已经实现全部组件。
