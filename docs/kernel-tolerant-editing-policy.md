# 内核宽容编辑与提示分级审计

状态：第二轮时间规则迁移完成；2026-09-17 已完成超拍、延迟声部起点、提示开关、任意尾部定位和删除时间策略。本文规定判断方法和后续实施顺序，不把尚未验证的规则直接降级。

## 原则

内核的严格性用于保护数据完整性、事务原子性、引用关系、版本一致性和可恢复历史。只要一个状态能够被模型无歧义表达，能够保存、读取、撤销、重做，并且后续操作可以修复，它就不应仅因音乐上不常规而被拒绝。

所有结果分为四级：

1. **阻断错误**：提交会破坏数据、身份、引用、精确运算或事务一致性，必须拒绝，用户不能关闭。
2. **规则警告**：文档完整且可以继续编辑，但可能违反常见记谱规则；内核返回事实，界面默认显示并允许关闭。
3. **建议提示**：风格、演奏便利性、排版或最佳实践建议；默认可关闭，优先由插件提供。
4. **能力提示**：文档有效，但当前视图、播放或插件暂不支持；必须保留文档，不应描述成用户输入非法。

提示偏好属于用户或工作区配置，不写入 `ScoreDocumentV1`。内核报告不因显示开关而变化，确保自动化、导出和不同用户看到相同的文档事实。

## 当前语义规则结论

### 保持阻断

- 空或重复 ID。
- 缺失的小节、谱表和扩展所有者引用。
- 重复或缺失的小节覆盖关系。
- 非规范分数、零或负事件时值、时间算术溢出。
- 无效拍号、无效移调参数和无法表达的书面音高。
- 空音符集合；该状态应明确转换为休止符，而不是保存成“没有音的音符事件”。
- 无效扩展命名空间、版本、负载和重复扩展身份。
- 版本冲突、陈旧锚点、权限失败、资源上限和非原子事务。

这些状态会让不同读取路径产生歧义，或使后续命令无法稳定定位数据，不属于可关闭提示。

### 已转换为规则警告

- `rule.sequence-exceeds-measure`：声部实际终点超过小节标称长度。没有业务超拍上限，警告携带标称长度、实际长度和精确超出量。
- `rule.sequence-start-after-measure`：声部起点晚于小节标称终点。非负、规范且可精确计算的起点继续保存和编辑；警告携带标称长度、实际起点和精确超出量。若同一声部因此也必然超拍，内核优先报告起点警告，避免对同一根因重复计数。

### 建议下一轮验证后转换

1. **移调后的发声音高超出当前播放范围**

   建议代码：`rule.sounding-pitch-out-of-range`。书面音高本身仍然完整，记谱和编辑可以继续；播放层可以静音该音、使用替代音源或报告播放限制。实施前必须确认导出和播放器不会发生数值截断。

2. **小节未填满**

   建议代码：`rule.sequence-underfills-measure`，并允许用户关闭。编辑中的未完成小节非常常见；可由界面选择显示隐式休止、显式补休止或保持开放尾部。当前 K1 的 `unsupported.sequence-duration` 已是能力分类，不应被宿主误当成文档损坏。

### 需要模型升级，暂不直接降级

- `pickupDuration` 大于拍号长度：当前字段表达的是弱起而不是通用不规则小节。若产品需要任意“实际小节长度”，应增加明确的实际长度或开放小节模型，不能借用弱起字段。
- 空谱面、无声部或无谱表文档：可以成为模板或草稿能力，但当前投影和部分命令依赖至少一个小节、声部和谱表。应先完成空状态协议与 UI，再改变准入规则。
- 非正速度：当前模型把速度作为必填播放参数。更合理的演进是支持“未指定速度”或自由速度标记，而不是保存零 BPM。

## 工作台中过于刚性的操作

以下属于编辑能力或交互策略，不应长期作为“非法输入”：

1. **音符与休止符不能互换**：应使用一个原子事务替换事件内容，并保留位置、时值、选择和一次撤销语义。
2. **中间休止符不能删除**：已解除。删除现有休止符会移除其时值并收拢后续内容，且可作为一个历史步骤撤销。
3. **只能在尾部空位插入且不能越过容量**：宿主容量条件已移除；任意稳定尾部定位可插入，超拍由规则警告表达。真正的陈旧版本或失效锚点仍返回冲突。
4. **删除音符必定自动变成休止符**：已提供“保持节奏／收拢时间”模式。默认保持节奏以兼容旧请求；收拢模式真正移除事件并前移后续内容。
5. **视图不支持即整页不可编辑**：跨谱表、复声部、特殊时值等应返回能力提示并尽量做部分只读投影，原始文档必须保留。
6. **小节刚好填满就自动创建下一小节**：适合连续输入模式，但应由输入模式或用户偏好决定，不应成为内核语义。

## 提示开关建议

- `showRuleWarnings`：总开关，默认开启。
- `ruleWarningCategories.rhythm`：超拍、少拍、延迟声部起点，默认开启。
- `ruleWarningCategories.playbackRange`：发声音域与播放能力，默认开启。
- `showSuggestions`：风格和最佳实践建议，建议默认关闭。
- 阻断错误和能力提示不受上述开关影响；能力提示可选择低干扰展示，但不能静默丢失内容。

工作台可以在关闭规则警告时显示一个低干扰计数，允许用户临时查看本次隐藏的报告。插件应声明自己的提示类别、默认等级和稳定代码，宿主统一应用用户偏好。

## 实施顺序

1. 修复所有解码、导入和保存重开路径对超拍的残留硬拒绝，并用多小节长度超拍回归冻结。
2. 完成工作台超拍布局、警告开关和任意尾部插入，不再把容量当成位置冲突。**已完成。**
3. 验证并迁移“延迟声部起点”。**已完成。** 整谱准入、增量事务、撤销／重做、保存重开和版本绑定警告页使用同一规则。
4. 引入“保持节奏／收拢时间”编辑模式，解除中间休止符和音符删除的单一策略。**已完成。**
5. 在播放器和导出器定义越界策略后，迁移“发声音高超范围”；在工作台确定隐式休止显示与提示密度后，增加“已有内容但小节未满”警告。两者不阻塞当前单谱表编辑。
6. 由插件扩展音域舒适度、指法、和声、排版和演奏建议；这些不进入微内核阻断规则。
