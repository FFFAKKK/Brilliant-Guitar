# 样式与宿主边界实施计划

2026-10-02。继续总规划第 2 项，沿用用户批准的备份副本范围与不建 Trellis 任务的选择。只在 design/frame-visual 实施，不修改原 frame 或废弃 workbench，不创建新的平台插件。

已确认的问题：base.css 的全局控件重置、焦点和动画规则、scrollbars.css 的通配隐藏，以及 structure-preview.css 的壳内所有按钮规则都会跨过插件挂载边界。

本批方案：用 data-frame-ui 标记框架自己创建的节点，标记不向子孙传播；内部 h 构造的控件主动采用框架皮肤，组件宿主仅标记自己的外层 cell 和故障提示。普通插件的原生 DOM 不自动采用框架皮肤。通用规则用零额外 specificity 的 :where 标记收敛，保留原声明值与优先级。纯静态侧栏审阅目录用 data-frame-document 显式采用文档 reset，不用于运行入口或插件承载容器。HTML/body 的窗口基线保留。

公开有限的颜色、字体、间距和圆角变量别名，保留现有 token 值。插件 CSS 采用自己的命名空间根选择器；这属于作者合同，当前不自动改写任意 CSS、不强制 Shadow DOM/iframe，也不宣称 CSS 安全隔离。

检查滚动、焦点、可见性、移动与清理：保留现有持久宿主和三个 ctx 方法，给拥有独立按钮、输入、滚动容器和样式资源的插件做模块集成测试。菜单/弹窗能力留到后续受限宿主接口，本批不增加新的弹窗服务或尺寸 API。

步骤：保存新基线与拟编辑原稿；引入逐节点标记并收敛通用选择器；补主题别名和作者样例；验证原声明值、选择器范围、默认结构、控件权限与生命周期；执行全副本回归、语法检查与新源码审计，记录真实浏览器未验收。

不改变布局几何、内置内容、视觉 fixture 或 Shell 结构。既有 file:// 浏览器访问拒绝保持有效，不通过替换协议或浏览器绕过；静态 CSS 合同与 DOM 替身不能证明计算样式或像素一致。
