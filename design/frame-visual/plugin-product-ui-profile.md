# 本产品 UI 插件接入与视觉要求

日期：2026-10-04。范围：备份框架 `design/frame-visual`。本文整理已约定的本产品要求，没有修改运行样式或布局。

本文与 [通用插件设计原则](./plugin-design-v0.1.md) 分开维护。四栏、谱页居中、边缘样式和滚动条表现是本产品的接入要求，不自动成为外部插件平台的通用合同。

## 1. 宿主与内容的视觉职责

宿主持有区域几何、入口槽位、命中范围、选中状态、焦点反馈及组件实例关系。插件负责自己内容中的图标图形、按钮、配色和排版，可以选择使用宿主公开的主题变量和基础控件。

插件内部样式使用自己的命名范围，不覆盖宿主控件或其他插件子树。当前平台不自动改写作者 CSS，也不提供完整的第三方代码强隔离；实际样式边界见 [样式合同](./style-boundaries.md)。

当前入口图标字段按名称查询已有图标；自定义 SVG／图片入口资源合同尚未开放。插件自己的内容图标不因此取得修改宿主图标表的能力。

## 2. 四栏与组件配置

用户可见名称统一为上侧栏、下侧栏、左侧栏、右侧栏，不用业务名称定义通用区域。

四栏开关、尺寸、单项尺寸恢复和几何排布随时可用。编辑模式管理栏内组件配置；打开布局页不自动进入编辑。现有实际内容管理只接入左右侧栏；上下栏内容管理继续留后续。

组件允许位置来自作者声明。跨栏移动保持贡献身份和实例；布局取消处理约定的组件配置，保留日常区域几何、组件私有输入、业务状态及阅读位置。

左右侧栏预制样式及选择功能留后续。内容不以固定页签、列表或网格样式定义身份；选择样式的能力需要单独合同和视觉验收。

### 谱面工作区也是插件承载区域

主谱面视图属于工作区内容；获准的固定工具和辅助面板放在工作区内部左右两侧，与谱面阅读视口分别占位，不遮挡谱面。右键菜单等小面积内容可以临时悬浮。位置以宿主合同表达，区分工作区布局空间、触发点与谱面元素锚点，不由插件查询私有 DOM 实现。

该能力属于目标设计，尚未开放当前作者字段。固定组件的位置、顺序及相关尺寸配置纳入布局编辑；日常谱面浏览、选择、输入、业务操作和临时菜单打开／关闭继续可用。临时菜单由宿主按触发点或公开锚点定位，不保存临时布局坐标；Escape 关闭菜单不取消布局会话。详细规则及真实视觉验收见 [工作区位置设计](./score-workspace-placement.md)。

用户确认首版先提供主体及工作区左右固定预设位置，之后增加自由放置。工作区插件区与原左右侧栏分别表达；放大时由宿主自动收起原左右侧栏让空间，退出放大或空间恢复后按侧、按属性恢复，保留期间手动开关和尺寸调整。自动收起不搬迁原栏内组件，期间四栏日常操作仍可用。触发条件与空间阈值待工程验证，当前运行代码尚未实现此策略。

## 3. 谱页、边缘与滚动表现

- 普通区域操作保持既有谱页位置与尺寸；窗口变化按宿主既有规则保持水平居中。
- 保持工作台与侧栏的分区；常态边缘透明，布局选中边缘沿用蓝色反馈。
- 长内容仍可滚动浏览，按本产品要求隐藏浏览器式滚动条。隐藏滚动条不意味着禁止滚动或键盘浏览。
- 插件使用自己的内容容器，不直接移动谱页、修改宿主区域尺寸或写入权威布局状态。

这些规则是原有视觉约定的文档归位；具体几何行为以已有窗口适配、侧栏呈现及运行验收为依据。

新增工作区承载接入后，谱页居中以分配给主体的阅读视口为参照，固定插件区占用独立空间。视口不足时仍可滚动／平移浏览，不通过固定面板覆盖谱面或自动改变用户缩放值解决空间问题。临时浮层的最大面积、边界及长内容浏览方式在其公开合同中明确并实测；本段是后续验收要求，未修改既有布局。

空间预算和实际阅读视口的工程边界见 [宿主接入合同草案](./workspace-host-contract-v0.1.md)。新增能力接入与启用新产品编排分别验收；旧入口继续对照既有画面，新固定区的容量、溢出表现及最低可读范围用实际窗口定版，不从旧侧栏尺寸直接推导。

## 4. 接入后的真实视觉验证

有视觉内容的测试插件至少记录实际窗口尺寸、内容规模和所用宿主修订，检查：

1. 最小及常用窗口下的可读性、入口容量、内容溢出与空态。
2. 四栏开关、尺寸变化、跨栏移动与取消后的谱页稳定和组件状态。
3. 鼠标及键盘焦点、文本输入／输入法、必要菜单与确认窗口的关闭和焦点返回。
4. 长内容的滚动浏览及滚动条表现，插件样式对相邻内容和宿主控件的影响。
5. 隐藏、恢复及释放后的视觉残留；实际使用动画时再检查关闭／减少动效。
6. 开放工作区承载后，验证两侧固定内容不覆盖谱面、主体视口居中与空间不足时的阅读；放大自动收栏、退出／空间恢复以及期间手动开关和尺寸调整均按约定保留，连续空间变化不反复收放。
7. 开放小面积临时浮层后，验证触发位置、边界、内容容量、菜单键盘／输入法、点击不穿透、关闭及焦点返回；不形成持久布局坐标或取消底层编辑。

DOM 替身验证结构和逻辑；真实浏览器验证布局、焦点、系统输入及像素。两类证据分别记录，通过范围按实际检查场景说明。
