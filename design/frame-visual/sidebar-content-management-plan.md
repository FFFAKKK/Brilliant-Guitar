# 真实侧栏组件管理接入计划

日期：2026-10-03。用户批准接入已讨论的真实组件管理；沿用不建 Trellis 任务的选择，只在备份副本 design/frame-visual 内实施，主会话直接实现与检查。

需求：布局编辑页读取已登记内容，显示所在侧栏、加入状态与允许位置；添加/移出已有内容、左右移动、排序；即时预览，统一确认/取消；四栏日常开关与尺寸独立。添加/移出只是 setEnabled，不安装/卸载插件，不生成新实例。界面使用现有布局设置区样式，外层结构、CSS 和尺寸常量保持。

设计：贡献目录 + 编排只读端口 → 内部内容管理数据投影 → 布局页设置区。写入仍为 ctx.execute → 唯一 UI router → 原布局编辑会话 → 编排状态 → 持久组件呈现。目录投影不持有新配置 store，组件 ctx 不新增成员，作者 slots 和 v1 协议保持。会话提供只读最终组件差异用于修改列表，避免布局页另存组件回滚基线。

工作区布局页是固定入口，不加入普通内容选择列表；会话拒绝它的移动、停用与排序，直接 handler 和 router 使用同一政策。位置能力只来自作者声明，当前内置内容仍限定 right；上/下侧栏内容管理、样式选择、拖拽、持久化和热插拔属于后续批次。

执行：保存 fresh 源码哈希和原稿；接只读数据与保护政策；复用现有 controls 加选择/加入/移出/位置/排序设置；组合根与布局页接端口、权限、订阅及释放；测试真实贡献目录和命令链、不可用状态、确认/取消、实例与输入保留、失败反馈与清理；完整回归、语法检查、批次源码审计和差异归档；同步副本作者合同和 roadmap。

验收：默认入口显示真实内置内容，不显示 fixture A/B/C；模式与权限不能绕过；不支持的位置明确不可用；移动/停用/恢复/取消保持同一已挂载实例和输入；确认后的下一次取消回到确认状态；排序反映到页签/内容；取消不还原尺寸或开关；缺失贡献与空集合有一致反馈；pagehide 和失败挂载清理订阅。

证据保存 evidence/sidebar-content-management/，旧 evidence 不覆盖。DOM 替身只验证实际模块装配和状态/命令流程；真实浏览器像素、原生焦点和 IME 仍待验收，已有 file:// 访问拒绝不绕过。原 frame、废弃 workbench、外层 Shell、几何、CSS、router、平台及作者 slots 将由源码哈希审计。
