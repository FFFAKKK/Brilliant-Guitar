# 框架控件与承载视觉规范

revision-11，2026-10-03。来源为批准备份及已接受修订。本规范只定义框架拥有的操作和承载空间，插件内部控件由插件作者设计；不是新的插件API或工程实现。

## 最高视觉原则：关键文字，其他优先图形

框架常态只保留关键内容文字。能够由图标、形状、位置或状态表达的操作，不使用密集说明句挤占布局；改用图形入口，并通过可访问名称与用户主动触发的 tooltip 提供解释。新增文字必须先证明它是关键内容，或属于错误、状态、确认和不可推断名称。

## 责任与采用方式

框架负责区域开关、尺寸、页面入口、导航、内容管理、布局组件和框架浮层。插件提供入口图形以及内部按钮、字段、配色与排版。宿主统一入口槽位、对齐、热区、当前状态和焦点；保留图形本身，不把框架图形替换为插件统一标准。

`h(tag, props, ...children)`只给新建的框架节点标记`data-frame-ui`，不标记插件子树。`framework-controls.css`只作用于显式标记的控件。`visualButton(label, glyph, action, options)`是现有框架内部工具，其签名不变。frame/v/fc类及几何token都是私有实现，插件不得依赖这些类作为公开接口。

插件可自愿使用已有八个`--ui-*`主题变量；字体、文字色与color-scheme会继承，作者可在自己的根容器覆盖。没有强制共享按钮库，也没有iframe/Shadow DOM强隔离或自动CSS重写。作者样式限制自身命名空间，避免全局button/input/body/:root/*选择器。保持现有注册、实例、命令、键盘和持久化合同。

## 宿主尺寸与密度

| 框架对象 | 既有尺寸/本批规范 | 字号与间距 |
| --- | --- | --- |
| 文字操作/输入/下拉 | 常用28px高；文字按钮左右8px；输入左右6–8px | 操作12px；布局数值11px；内容从自身区域继承 |
| 图标操作 | 常用28×28px；单项恢复24×28px | 图形14–16px；不扩大外壳几何 |
| 侧栏导航入口 | 32×32px热区，40px图标列 | 图形居中；图形身份由提供者决定 |
| 内容行 | 最小32px高 | 图形、主文字、数量分列，间距8px |
| 区域开关 | 常用36px行；紧凑区域开关沿用28px | 标签12px，24×14px开关示意，间距8px |
| 区域标题 | 32px高 | 12px/500，数量11px |
| 页签/翻页/数量 | 沿用所属框架28/32px操作高度 | 单项当前底色；数量11px、等宽数字 |
| 帮助/限制/状态 | 文字换行，保留所属区域宽度 | 常用11px；现有布局容量10px；1.6行高 |
| 承载间距 | 沿用4px节奏；侧栏内常用12px | 独立组之间16px，相关操作4–8px |

上述是实际框架皮肤和审阅值，不要求插件内部采用同样字号或热区。本页没有新增未使用的滑块、日期、业务表单等控件。

## 状态规则

| 状态 | 视觉与操作 |
| --- | --- |
| 常态 | 边缘透明；用底色、对齐、留白表达操作位置，没有白色/浅灰装饰框 |
| 悬停 | 框架hover表面；主要确认按钮保留蓝色，再轻微提亮 |
| 按住 | 即时深色反馈；主要按钮保留蓝色并压暗；不加动画 |
| 当前/选中 | 淡蓝承载底色和当前文字；普通组件不加边框，内容编辑仅当前选中组件蓝边 |
| 键盘焦点 | 蓝色2px轮廓、1px偏移；数值框焦点标识整个数字与单位容器；不改变布局尺寸 |
| 禁用 | 原位保留、使用frame-disabled文字、无hover/active反馈、不进入Tab；旁边说明具体原因 |
| 只读 | muted文字；仍可聚焦、选择和复制；禁止修改，不冒充禁用 |
| 错误 | aria-invalid和邻近原因/处理文字；错误数字与说明使用danger文字，不加红色/白色装饰边框 |
| 长内容 | 框架按钮/内容行限定宽度省略，保留完整名称提示；输入保留原值并可移动光标；帮助文字自然换行 |

真实禁用使用原生disabled；只读用readonly；开关/选项组沿用aria-pressed；页签用tablist/tab/tabpanel及aria-selected。审阅页页签采用单Tab入口、左右方向键及Home/End切换。这只用于本页导航，不改变产品全局键盘工程。

数字输入保留既有值/范围/恢复路径；本页200–360px数值是中性演示范围，不能代替实际工作区窗口容量。去掉框架原生数字微型步进按钮，继续允许键盘上下键和已有恢复操作。下拉只统一关闭状态及箭头，展开仍是原生选择器；完整框架浮层与边缘定位属于第六批。

## 承载与容量

审阅页有200/260/360px侧栏与40/64/96px上下横栏组合。内部控件保持min-width:0，文字或说明按规则省略/换行；热区不被压扁。框架可浏览区域隐藏滚动条，滚动、键盘焦点移动仍能到达尾部。插件自身内容由插件管理空间与浏览，并应遵守整体不出现浏览器式滚动条的视觉要求。

常态承载边缘透明，框架不为所有私有内容画边框。私有样式探针仅用于验证不侵入：不同字形、圆角、色彩、边线和焦点保持原样；它不是拟定的外部插件设计。窄区域中插件作者负责自身响应式表现，框架不静默重排私有控件。

控件反馈不会重排外壳；工作区普通操作继续固定谱页X/Y/宽高，resize保持纸宽/Y并按窗口中心对齐。侧栏与工作台分区；上下展开共同缩短左右可用高度、默认左右宽度对称。
