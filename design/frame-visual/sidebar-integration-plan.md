# 侧栏呈现接入计划

2026-10-02。用户已授权开始。实施与 70 项相关回归已通过，正在记录最终范围审计。沿用会话中不建 Trellis 任务的选择，仅在备份视觉副本实施。本批新增 UI 宿主内部适配模块，不新增平台插件。

## 范围与所有权

- 现有 UI 命令路由器保留在 UI 框架包内部，由默认组合根创建一个共享实例。宿主操作与业务插件贡献登记到同一实例，不增加另一命令总线。
- 默认入口从既有平台查询统一 panel 目录，建立固定启动集合的编排状态；原内置包的 v1 声明继续兼容，中央谱页和业务内核不改。
- 新呈现适配器从目录与编排生成左右侧栏数据，使用 componentId 复用实例。左侧采用当前列表承载，右侧采用当前页签承载；默认四项继续位于右侧，左侧仍为空。
- 既有 workspace-state 继续拥有几何与 currentPage。currentPage 在本批作为右侧页签的兼容选择偏好，实际选中项从已启用且位于右侧的内容派生；无可用偏好时选择第一项，全部关闭时为空。没有再创建第二份选择状态。新增 navigatePage 与可选有效选中 id，使翻页保留区域显隐，点击回退选中项也能折叠；已有调用、几何字段和尺寸规则继续兼容。
- 旧 footerHeight 属于当前页签呈现的兼容提示，由组合根单独交给呈现层，不回填通用目录或编排状态。新 panel 作者合同不因此增加样式字段。
- 页签、区域展开与 enabled 联合决定实际可见性。隐藏不释放，未可见且从未挂载的内容保持懒挂载；组件消失和最终宿主释放沿用原清理合同。

## 实施顺序

1. 捕获本批新基线和计划；检查旧默认结构。
2. 新增呈现适配与直接调用编排的方法绑定；接入已有默认入口和 Shell，仅修改内容消费和生命周期代码。
3. 补齐实际适配、别名、排序、空侧栏、失效内容、单次路由、错误回滚和资源释放测试。
4. 使用 DOM 测试替身对照基线 Shell 的默认结构与页签状态，运行相关回归与语法检查，单列并发修改和原件清单/哈希。

## 验收与限制

默认几何、CSS、图形和内置内容不由本批修改；默认 DOM 对照应一致。以 AI 助手输入框验证切换、折叠和恢复保留节点与文字；实际呈现适配器的左右移动用独立测试验证，不为测试放宽内置内容的允许位置。

浏览器工具拒绝 file:// 协议访问，不能执行本批浏览器截图对照；不通过其他协议或浏览器绕过该拒绝。完成源码与 DOM/实例验证，明确像素级浏览器验收仍待完成。

预制样式、样式选择、持久化、内核业务接入和正式发布包不在本批范围内。
