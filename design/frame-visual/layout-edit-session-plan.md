# 命令层布局策略与统一编辑会话

2026-10-02。用户要求继续总规划第 3 项，沿用不建 Trellis 任务的选择与备份副本实施范围。原 frame、废弃 workbench、CSS、视觉 fixture 和几何常量不由本批修改。

唯一模式为已有 workspace.adjusting。workspace 与 sidebar composition 继续拥有自己的状态；内部会话保存配置回滚边界，复用两者同步批处理能力，不复制业务数据、不创建平台插件或新命令总线。预览继续直接呈现现有状态；确认保留，取消还原几何与全部侧栏身份/位置/启用/顺序。

配置命令：尺寸、排布、明确的区域配置、侧栏移动/启用/排序必须处于编辑会话。普通区域收放、页签导航和缩放继续可用。enabled 提供入口状态，处理函数内再次检查政策，不能仅依赖按钮禁用。

顶部配置与编辑 chrome 分离：begin 不改 topOpen，Shell 根据 adjusting 或 topOpen 显示操作条，confirm 不强制还原旧顶部配置。布局页使用受限的 configureRegion 命令，原 region.toggle 仍为普通收放。进入编辑的右侧布局页导航保留原行为；退出不回滚用户输入、业务选择、阅读位置、窗口视口或谱面文档。

两状态批处理在通知前一起完成；返回失败或抛错恢复各自原状态与快照，不发部分通知。批处理仅支持同步配置变更；拒绝异步回调。观察者错误隔离，不把呈现观察者异常当作已提交配置需要回滚。侧栏 restore 验证固定身份与能力边界，不导入未知项或扩大 slots。

步骤：保存 fresh baseline 与 13 个原稿；实现内部同步状态事务与会话；接入默认组合根和两个命令绑定；更新测试以明确进入编辑再配置；验证普通操作、权限/快捷键、统一取消/确认、错误原子性、通知一致、视口变化与私有状态保留；回归、语法检查、新源码审计与作者说明。

本批不增加真实内容管理界面、保存、预制样式、任意配置事务 DSL 或业务编辑。现有 file:// 浏览器拒绝不绕过，DOM 测试不计为原生焦点、布局或像素验收。
