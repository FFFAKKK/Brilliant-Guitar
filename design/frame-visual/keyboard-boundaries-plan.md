# 焦点与快捷键边界实施范围

2026-10-02。沿用用户已确认的备份副本与直接实施范围，不新建 Trellis 任务。

本批补齐默认运行入口的键盘边界：字段和瞬态界面保留原生/局部操作，当前可见组件优先处理，未处理的按键才进入已有全局命令或工作区 Escape 行为。谱面视图只在焦点进入其实际组件实例时处理键盘；侧栏不向后台谱面转送按键。

组件实例可以提供同步 `handleKeyDown(event)`：返回 true 表示消费，false/undefined 表示交还；已有局部 DOM 监听通过 preventDefault 或 stopPropagation 消费。动作继续使用 ctx.execute 和原权限白名单，不新增注册表、命令路由器、平台插件或 manifest 字段。全局命令的 keys 仍保持唯一；局部同键通过各实例焦点隔离。同步错误或错误返回类型消费当前按键并报告，避免错误穿透到别的动作。

隐藏、切换或移除当前聚焦内容后，宿主把焦点移到当前可见页签或谱面舞台。可见内容移动与重排保留焦点和节点身份。键盘入口支持幂等解绑，默认入口随 pagehide 释放。

步骤：

1. 保存新基线和拟修改文件，不复用之前批次哈希。
2. 实现内部焦点识别、组件局部 hook、单一键盘入口和可释放绑定。
3. 默认运行入口接入；工作区移除独立 window Escape 监听，保留现有取消与焦点返回行为。
4. 验证字段、输入法、瞬态界面、实例所有权、隐藏/销毁、同键冲突、失败隔离、焦点恢复及真实 Shell 接入。
5. 回归已有测试，记录源码审计和限制。
