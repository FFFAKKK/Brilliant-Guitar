# 共用动作状态：第 5 批第一步

日期：2026-10-03。用户要求继续后续工作，本步接动作状态读取与实际按钮同步。沿用不建 Trellis 任务的选择，主会话直接实现/检查，修改限定 design/frame-visual 备份副本。

需求：布局页的按钮读取原命令 enabled 和有效快捷键，不只依赖 adjusting；会话不可用、命令缺失或未授予权限时正确禁用并说明。命令的 checked、可用性和有效键位形成同一个只读数据接口，供后续菜单/弹窗消费。原 ctx.execute/notify/onDispose 和唯一 router 继续执行实际动作，位置/顺序/启用字段仍由各状态所有者负责。

设计：新增 host/action-state-read-port，输入受限命令 id 集合、实际组件快捷键上下文和只读状态通知源，返回冻结 snapshot/subscribe。无 command.run、注册方法或执行方法，不持有状态副本。组件名单与权限由默认组合根从实际组件登记提取。订阅 router（包含键位变更）和工作区/编排状态，任一通知时重新读取。每个消费者自行释放订阅；失败注册回滚已取得资源。

新增 shell/action-presentation 做控件 disabled 与提示的纯更新，业务位置限制继续保留。布局页、组件配置区、尺寸/开关/排布控件接可选 action 只读端口；旧独立装配缺省仍沿用原行为。操作前再次读取状态，执行仍经过原权限与命令层。状态回调应同步、无副作用，非法或抛异常时该动作显示不可用，其他动作继续读取。

执行：fresh 哈希与原稿；只读投影及订阅清理；控件提示复用；组合根/布局页接线；专项测试覆盖真正的权限拒绝、会话失配、命令移除、状态更新、映射上下文及改键/取消/恢复、失败谓词隔离、注册失败清理、一次受限执行、持久控件和默认入口；全回归、语法检查、源码审计与合同归档。
