工程测量基线不等于发布阈值；具体最低设备及数字门槛在第一次资格实测前冻结，不在看到结果后调整。

2026-10-08用户已选择最低规划目标Windows／4核CPU／8GB内存；实际参考设备仍待登记。绘制部分的首版工程门槛已在[策略](notation-capacity-policy-v0.1.json)冻结，运行方法与限制见[绘制容量指南](notation-capacity-guide.md)。未指定referenceDeviceId，不能从开发机或浏览器hardwareConcurrency推导最低设备资格；其他阶段的门槛仍待。

## 本轮可执行的基线

```text
node design/frame-visual/tools/measure-foundation-capacity.mjs --output design/frame-visual/evidence/author-development-qualification-20261008/capacity-baseline.json
```

工具使用现有四小节预览输入生成16/128/512小节，每小节四事件，分配唯一小节/voice/event ID；校验输入后调用真实共享分页算法。
每规模预热3次、采样25次，记录原始normalize/layout时延、nearest-rank中位数/p95/最大值、页面数量、输入哈希、来源指纹和本机CPU/内存/Node版本。
所有规模和采样方式在执行前确定。报告status=baseline-only、thresholds=null、G6=pending。

这个Node测量仅覆盖快照校验/复制/冻结及纸张分页。它不执行VexFlow、字体度量、SVG挂载、原生文件IO、桌面启动、指针或缩放。
进程RSS/heap快照没有强制GC，不当作泄漏结论；本机不是自动认定的最低支持设备。已有100次循环继续作为受控资源回归。

## 真实格式文件与宿主基线入口

```text
npm --prefix design/frame-visual run foundation:measure-files -- --output design/frame-visual/evidence/new-document-capacity-candidate
```

output必须为仓库内尚不存在的新目录，父目录已存在。工具通过原factory/公开命令初始化确定音乐，再经过真实ScoreSessionService Native导入和原exportDocument生成空谱及16/128/512小节`.bgp.json`；512含2048个事件。不会把预览投影改名为文件，也不放宽产品新建128小节限制。

每规模预热3次、测25次，分别记录Node文件读取、UTF-8/JSON解析、host导入/Native读取、备份真实文档投影和分页。输出实际文件、后续绘制可用的投影、坏文件、原始样本、Native addon/源/输入指纹。当前读写格式为brilliant-score-1的UTF-8 JSON，未来`.bgp`包装格式不计入本轮。

这是warm文件/宿主/分页基线，依然不执行Rust文件对话框/IO、IPC、VexFlow/SVG、WebView或冷启动。status为baseline-only、阈值为空、G6待验；具体字段与失败规则见[文件容量合同](../../.trellis/spec/frontend/document-capacity-contract.md)。

## 下一轮执行前的输入与记录准备

1. 为本次候选填写设备表、实际EXE/资产哈希、系统缩放与电源模式；另填拟支持的最低设备。阈值在采样前写入独立冻结文件，缺少设备或阈值时只生成基线，不授予G6。
2. 用既有原生格式写入器在独立evidence夹具目录制作空谱及16/128/512小节文件，记录SHA256、字节数、期望事件/页数和音乐元素。先通过原作品读取及投影校验，不直接将合成投影改名为作品文件；保留合法文件和独立损坏副本，不使用用户作品。
3. 将“读取/投影/分页/绘制/DOM采用/画面可操作”分别记录。现有Node工具只覆盖前述校验/分页；真实WebView记录应包含字体就绪及实际SVG采用版本，未完成阶段记pending。视觉正确性由同版记谱/几何验证确认，不用速度替代。
4. 冷启动和热操作分开采样，分别预先填写轮数、预热、起止事件、计时方法、失败和超时阈值。保留每个原始样本及失败，不删除慢值；使用既有nearest-rank统计。报告当前源前后指纹，变化为stale。
5. 长时间资源试验先固定“打开A→打开B→坏文件保留B→重读→隐藏/移动面板→结束会话”的序列、轮数与采样窗口。记录节点、订阅、监听、动画与进程内存趋势；不凭一次RSS或未强制GC的heap值判断泄漏。

上述准备中的真实规模作品现可通过foundation:measure-files生成并验证；本机首轮证据另附。完整G6的实际最低设备/其余阶段阈值、WebView绘制与长期资源仍未完成。无需增加性能平台或改变音乐算法。

绘制入口现为notation-capacity-preview.html：使用原真实文件投影、唯一渲染/加载器及全部样本；无实际浏览器执行则不产生绘制通过声明。工程数字目标只覆盖绘制入口的限定路径，完整G6阈值/设备/长期资源仍未完成。
