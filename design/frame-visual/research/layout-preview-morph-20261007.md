## 已完成与可见操作

1. 点击尺寸行前的四个区域图标：对应区域收拢到 3px 暗条；重新打开恢复偏好尺寸。中央示意区连续衔接，真实谱面不扩大或移动。
2. 拖动四个尺寸滑条或输入数字：尺寸、填充、thumb 和示意即时同步，左右/上下引用同一组框架范围。单侧调整不改对侧值。非法数字草稿暂不改变接受结果，离开后按范围限制并回写。
3. 排布行三个图形按钮：均衡使用默认成对尺寸并保留显隐；紧凑使用框架紧凑尺寸；恢复默认同时恢复四区域显隐与尺寸。
4. 关闭区域时只禁用同行尺寸控件，开关仍可操作；读屏名称/按下态保留。静态选中底色复用原图标选择样式，不增加白色围框或重复文字。

正常节奏：连续 280ms、聚焦 260ms、静稳 140ms；慢放 2.5 倍供观察。区域明暗和几何使用同一进度，没有独立颜色定时器。尺寸输入、键盘、窗口、减少、关闭和隐藏即时；快速反向从当前裁剪与位置接续，不重置到原端点。

- 作者：`src/fixtures/motion-pilot/layout-preview.js` 拥有示意比例、私有控件、触发和纯投影；`layout-motion-definitions.js` 的 review 包装拥有新曲线。

- 执行：唯一适配器通过现有 Motion 本地产物写完整 translate3d 与 clip-path。所有色块固定 512×512，无 CSS 布局尺寸动画、字体缩放或新增引擎依赖。
- 原 `LAYOUT_MOTION_CONTRIBUTION.animations` 与正式私有参数继续共享同一引用，只有 `LAYOUT_PREVIEW_MOTION_CONTRIBUTION` 追加 shape-transition。正式 ui-motion/1 仍仅支持原三动作，没有几何能力；本样稿不冒充正式插件迁移。

接口是 `port.play({intent:"shape-transition",target,to:{x,y,width,height,opacity?},from?,immediate?})`。x/y/width/height 必填、有限、非负，两端总和不超过 512；opacity 可选 0–1。拒绝 velocity、spring、任意 CSS/timing、外壳/谱面目标；先验证再取消已有工作。矩形用例依然经过同一个 bind，没有额外身份、注册或业务出口。
