# 三页启动中心视觉草案

本切片为独立视觉预览，正式启动入口不变。沿用用户接受的备份框架及插件管理布局；不增加平台、router或真实最近文件/设置存储。

## 设计依据

颜色直接使用原tokens：canvas #1c1d20、command #242529、surface #2d2f35、ink #f2f0eb、muted #afb1b8、focus #8fb7ff。字体使用原Segoe UI／Microsoft YaHei UI栈，正文12–13px、页面标题15px、品牌13px；没有巨型标题或装饰性渐变。

窗口约980×600，固定短导航宽144，内容左对齐。首页为紧凑最近列表与右侧小谱面预览，顶部小型新建/打开按钮；插件页从原HTML提取壳并消费原view/controller；设置页只演示当前预览的密度/字号。窄屏把导航变横向，预览移到列表下方；不靠负margin或单按钮偏移修图标。

```text
┌ 品牌          ┬ 当前页标题   新建／打开／搜索 ┐
│ 最近          │                              │
│ 插件          │ 最近列表         小谱面预览   │
│ 设置          │                              │
│               │                              │
│ 视觉预览      │                              │
└───────────────┴──────────────────────────────┘
```

约束核对：仅关键导航/操作/名称用文字；其他统一图标与tooltip。没有大启动按钮、市场/账号/教学卡片。复用原approved-score.svg作为明确的示例缩略图，不手工画音符或暗示已读取用户最近作品。插件配置只保存到本页内存；页面退出即结束。原管理视图挂载一次，切页不重复初始化、不读产品存储。

交付为startup-center-static-preview.html及固定classic资产。导航/选择/搜索/设置预览可交互；新建、打开仅报告预览动作，不伪造成功工作区。新页面不进入原桌面资产清单。

实际浏览器检查仍受此前file://访问拒绝限制，不换协议/工具绕过。源、生成一致性和DOM生命周期检查不能代替真实像素/DPI验收；本轮只交付可由用户打开的视觉候选。
