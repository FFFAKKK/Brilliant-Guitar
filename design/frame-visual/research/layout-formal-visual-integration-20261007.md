## 当前交付

`src/features/workspace-layout-motion-recipes.js` 是不带身份、引擎或宿主依赖的布局私有作者模块；原审阅 wrapper 仅添加 motion-review/2 示例身份。同一份已有选择/内容/排序参数继续复用，新增区域示意的透明度 recipe。普通作者模块不是单独插件或第二个注册器。

实际布局视图 `createWorkspaceLayoutVisual()` 新增可选的私有 `attachMotion(bind, {onIssue})`、`setVisible(boolean)`、`dispose()`。默认不绑定，不改变已有静态外观。页面仍由工程会话通过正式协议绑定；本会话没有修改 workspace-layout-plugin.js / workspace-layout-page.js。

## 局部挂载约定（私有适配点，不是正式 SDK 字段）

视图已经 append 到组件自己的宿主节点后调用：

```js
view.attachMotion(({root, targets, animations}) => {
  // 工程会话将此私有 payload 适配为正式宿主提供的 owner-bound 端口。
  // 从已有插件身份取得 owner，不重新登记，也不复制 review 身份。
  return bindApprovedPresentation({root, targets, animations});
}, {onIssue: reportPresentationIssue});
scope.add(() => view.dispose());
// 页面实例 setVisible 必须转发到 view.setVisible。
```

`bind` 返回 null/undefined 表示提供者缺失，立即移除辅助节点，保持静态功能。提供错误端口或非法定义会抛出，宿主应经正式诊断/启动回滚处理。端口只需 place/play/dispose；play 必须返回 `{finished: Promise<{status}>}`。请求是已获准的局部 target + intent + 数值 + immediate，没有引擎、任意 CSS、业务修改和身份覆盖。

## 实际动作与范围

首个实际页面动作是“区域示意的状态强调”：四个内部 aria-hidden 的 `.v-map-region-ink`，目标名 `region:top/left/right/voice`，消费 content-transition 的 opacity 0–1，播放请求不携带位移，执行器测得 x/y 恒为0。区域模型、按钮语义和数字/滑条先即时接受宿主结果；动画只表达缩略图局部颜色覆盖，不能调整真实四栏、缩略图尺寸或谱面。

默认连续显现160ms、退场80ms；聚焦200/100ms；静稳140/70ms，沿既有作者曲线。系统减少/关闭由宿主端口执行。仅同步接受的真实指针区域开合正常播放；键盘、程序更新、窗口变化、异步接受及隐藏更新保守即时。滑条/数字输入不增加动画。隐藏立即 place 所有当前目标；重复隐藏不重挂实例；释放清理局部节点和许可。播放或诊断异常不抛回布局业务，恢复原静态状态。

初始与终态使用原来的单层区域背景；仅正在播放的区域设置 `data-motion-owned` 并显露 ink。完成 Promise 只释放该局部表现覆盖，不修改业务、aria 或尺寸；每目标记录检查阻止旧完成隐藏新动画，释放后完成无效。这样避免两个圆角表面叠加导致批准图形边缘改变。

本轮同时修正旧行级禁用语义：区域收起只禁用滑条/数字/恢复，区域开关及其祖先不应带 `aria-disabled=true`。视觉透明度沿 `data-open` 投影，颜色与外观保持。

这次没有声称“缩略图形变/分组揭示”完成：它们涉及新的图形轨道和实际 UI 结构。先把正式布局的最小动作接通并验收，再扩展，不能绕过现有属性许可。

## 工程会话需要补的接线

- 读取同一平台的正式动画贡献，校验/绑定身份与父组件归属，将此私有 payload 映射到正式执行服务。
- 页面 append view 后 attachMotion；在页面 onDispose/dispose 登记 view.dispose；实例可见性转发到 view.setVisible。
- 对缺失服务保留静态功能，对非法定义/越权明确拒绝。现有 notify/诊断路径按工程合同接入，不能因表现失败改变已经成功的布局命令。
- 跨组件内容目录仍是读投影；宿主保持命令、区域状态与事务的唯一所有者。

## 验收清单

- 静态初始/绑定后的初始像素和控件几何一致；四区域相互独立，无新文字/焦点节点/描边/滚动条。
- 指针点击先更新实际区域状态与 aria-pressed；中间透明度连续，快速反向从当前位置继续。
- 键盘、程序与异步接受即时；修改尺寸不产生局部播放或改变对侧；范围/数字输入继续沿原钳制合同。
- 减少/关闭、途中关闭、隐藏/恢复、移出或释放、两实例同名目标隔离；故障和迟到不能回写业务。
- 正式预览中实测四栏开合/尺寸与固定谱面、实际页面关闭/打开、退出清理。独立浏览器中的受限注入证明私有视图可用，不代替正式平台装配验收。
