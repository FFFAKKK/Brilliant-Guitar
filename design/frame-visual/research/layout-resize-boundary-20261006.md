# 工作区尺寸滑条边界复核

## 决定

保留三种尺寸入口：侧栏边缘把手用于直接拖拽，工作区布局组件滑条用于集中调整，数字输入用于精确输入。三者共享同一套工作区钳制逻辑。

左右侧栏使用统一的产品级上限 `420px`。窗口或另一侧空间不足时，当前可接受上限可以动态降低；这不会改写另一侧已经保存的尺寸。

## 防止死区

每个滑条的视觉轨道终点必须等于该控件当前的可接受最大值。不能使用另一侧更大的上限作为轨道终点，否则会出现滑块继续可拖、宿主却把值截回的无效区。

## 当前实现

- `WORKSPACE_MAXIMUMS.left/right` 统一为 `420`。
- `layoutDimension().trackMaximum` 直接使用当前控件的 `maximum`。
- 宽窗口下左右默认值仍为 `260px`，滑条起点和终点对齐。
- `1024×720` 下左右动态最大值为 `232px`；`800×600` 下为 `230px`。
- 真实浏览器验证了左侧栏可以从 `260px` 调到 `400px` 和 `420px`，滑块分别落在对应位置，右侧栏数值保持 `260px`。

## 验证

- `npm test --prefix design/frame-visual`：363 项通过。
- `git diff --check`：通过。
- 1440×900、1024×720、800×600 浏览器检查：滑条 `max` 与 `aria-valuemax` 一致，页面没有页面级溢出。
