# 通用承载与内容管理视觉规格 · revision-12

2026-10-03，第四批。来源为批准的备份外壳、已接受修订及结构文档中的呈现/布局要求。以下尺寸与反馈为视觉规格；配色、图标与具体功能内部由相应组件会话设计。

## 入口与范围

`content-hosting-review.html`提供状态目录，`structure-preview.html?contentReview=1`提供可操作样稿。默认结构入口及runtime不装入这些内容。左右各有两页，分别从grid/tabs/mixed/list开始；每页可在布局组件选择自己的呈现。同页mixed按内容归属分区，每项身份只出现一次。

A–K是内存视觉样稿，不注册为插件、不写入工程存储、不代表业务界面。每次渲染通过身份读取输入/选项/阅读记忆；这仅验证视觉连续性，不证明实际实例DOM复用。工程必须沿用已有注册、slot、编排、实例生命周期、命令许可与键盘接口，真实隐藏不卸载、跨区域移动不重建实例、缺失恢复和持久化仍由工程验证。

## 容器与页面

| 部位 | 视觉规格 | 容量与状态 |
| --- | --- | --- |
| 区域标题 | 32px，左/右同一结构 | 区域名、收起入口固定；省略长名称并提供完整title |
| 承载页导航 | 32px | 当前页/总数、前后按钮；首末禁用，单页两端均禁用 |
| 内容阅读区 | minmax(0,1fr)，12px内距，8px横间距 | 无滚动条，滚轮/键盘可达末尾；按页面及呈现/页签身份记忆 |
| 页面固定区 | 基础56px，8px×12px内距 | 独立浏览；请求过高时保留96px阅读区，再限制固定区，可查看容量原因 |
| 固定区极低容量 | 最小40px | 当前区域不足时限制固定区；不可因此自动关闭其它栏或缩小纸页 |
| 内容最小宽 | 样稿各自声明92/96/120px | 真实最小宽由组件声明，不要求插件采用样稿数值 |
| 网格半行 | (侧栏宽度−24px内距−8px间隔)/2 | 宽度不足保持原占宽、给原因；可主动扩大侧栏，禁止新加入仅半行且放不下的内容 |

页面固定区与具体插件自己的固定区是不同层级；样稿只验证外壳容量，插件内部排布由组件会话确定。宿主的滚动约束不向插件内部递归套用私有样式。

## 四种呈现

- 页签：承载页导航与内容前后导航分开。独立页签的28px内容导航固定在阅读区外，长内容末尾切换不滚动正在离开的内容；mixed页签区内部贴顶。单内容、首/末按钮禁用；层叠页边只属于内容页签区，通过底色表达，不画白线。切换保留输入与该页签阅读位置。
- 列表：32px折叠行，名称占剩余空间，值状态靠右；展开内容与名称对齐。长名称省略，暂不可用/缺失显示文字原因；折叠状态属于普通浏览记忆。
- 网格：整行跨两列，半行独占一列，按原顺序放置；不同高度按内容本身高度显示。孤立半行后的空位独立保留，不用另一项自动补位。前/后边界禁用；拖放只允许所属网格区，跨区域与跨分区落点显示无效原因。
- mixed：页签/网格/列表区各有克制的文字标题和20px区间隔；每项只属于一个区。区内排序保持其他区原位，改变页面呈现不改变内容归属身份。

普通边缘透明；进入内容编辑后仅当前选中项蓝边。所有操作热区、焦点、禁用状态沿用framework-controls规格；无动画。插件提供入口图形，样稿使用中性图形，不设计插件标识。

## 内容管理与事务

右侧“工作区布局 → 编辑布局”为唯一配置入口。区域开合、尺寸和整体排布随时可用；页面切换、输入、选项、折叠、搜索及阅读也随时可用。

| 状态类别 | 归属 | 取消后 |
| --- | --- | --- |
| 每页呈现、成员及区内顺序、占宽、入口图标显隐与顺序 | 统一内容事务 | 恢复开始编辑时配置 |
| 内容跨区域移动、加入或移出 | 统一内容事务 | 恢复原所属页面；无重复实例 |
| 侧栏开合、尺寸、整体排布 | 工作区使用 | 保留用户调整 |
| 输入、选项、当前查看、展开/折叠、阅读记忆 | 普通使用 | 保留，不作为布局配置回滚 |

布局组件先选当前配置页，再选已加入内容，展示当前位置、呈现与区域许可。选择目标区域/页面后，按钮按原因可用或禁用；移动结果明确显示目标及“确认保留、取消撤回”。没有任意拖出窗口入口。固定内容、已在目标页、仅左栏、缺失来源、暂不可用和仅半行最小宽不足均有原因。

内容库同时表达来源、完整名称、所属区域/页面、已加入、正在查看、图标已隐藏、入口顺序与不可用原因。这些不是同一个选中状态。普通模式可搜索、查看已加入项和前往布局；加入/移出、显示/隐藏入口及顺序只有编辑中可用。全部入口隐藏时内容仍在原页面，可从库逐项恢复；搜索无结果有清空操作。隐藏入口不移出内容，移出也不清空私有输入。
