# 快捷键声明映射实施计划

2026-10-02。沿用用户批准的备份框架实施范围与不建 Trellis 任务的选择。本批只实现总规划第 1 项。

快捷键是 UI 包内部功能模块，有独立职责和资源清理，由组合根装配为一个共享实例；不是新平台插件。动作实现仍由原 UI 命令路由器持有。

合同：作者可声明 shortcuts 数组，每项为 id/command/keys/scope，component 与 score 作用域附 componentId；global 不指定组件，score 目标必须为本包 view。键位仅支持单次组合。绑定 id 稳定；用户只能覆盖 keys，空数组表示取消，reset 恢复默认，失败不修改状态。

旧 command.keys 生成以 command id 标识的 global 绑定；commandFor 委托同一映射实例。旧 command.describe().keys 保留声明默认值作为兼容元数据，实际消费者读取有效映射。平台使用同一批次验证规则处理待安装冲突、引用与权限；登记和安装失败逆序清理绑定。无第二张有效按键表。

分配顺序：字段/输入法/瞬态界面保护 → 当前实际组件的声明绑定 → 当前组件复杂输入 hook → 全局绑定 → 现有工作区兜底。局部认领后，缺失、禁用、拒绝和异常都不会继续触发全局动作。component 与 score 对同一目标具有重叠范围，同键视为冲突，不能依加载顺序选择。不同组件允许同键。

步骤：

1. 保存新基线和拟修改文件。
2. 抽取既有键位归一化，新增纯数据映射模块和内存覆盖 API。
3. 将命令 keys、作者声明、平台预检/安装/清理迁移至共享模块。
4. 接入实际组件身份、原权限执行路径、菜单与区域提示；组合根显式装配。
5. 验证原子冲突、旧包兼容、用户改键/取消/恢复、焦点/输入保护、权限/失败不穿透、生命周期和实际入口。
6. 回归副本测试、语法检查、原件与废弃 UI 完整性、新批次源码审计；记录作者示例和限制。

不加入改键设置界面、持久化、多键序列、宏、条件表达式、热插拔、额外平台插件或真实音符编辑。当前工作区 Escape 兜底仍作为既有交互保留，不擅自分配新默认键位。CSS、几何、内置内容、视觉 fixture 不由本批编辑。已有浏览器访问拒绝不绕过，测试替身不冒充真实浏览器验收。
