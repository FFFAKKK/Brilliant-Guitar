# 框架键盘与可读性视觉合同

日期：2026-10-04，revision-15 视觉交付及插件边界补充。范围为备份视觉框架及内存样稿；不增加插件SDK、快捷键平台或业务功能。核心视觉结果见[历史验收](evidence/revision-15/review.md)，本次内部解耦见[边界复核](plugin-boundary-review-20261004.md)与[局部复测](evidence/plugin-boundary-review-20261004/review.md)，流程入口见[审阅目录](accessibility-review.html)。

## 所有权和函数

`src/shell/frame-accessibility.js`提供框架内部函数：

```js
prepareFrameReading(root) // 标记显式拥有的阅读容器，按容量更新Tab可达性
installFrameReading(root, { signal }) // 委托阅读键和焦点显示，随原生命周期释放
readingKey(scroller, event) // boolean；仅处理未被保留的普通阅读按键
captureFrameFocus(root) // 返回重绘后的恢复闭包，仅用于纯视觉样稿
revealFrameFocus(node) // 只调整框架阅读祖先，不滚动谱页或整张页面
```

仅操作指定类名且带`data-frame-ui`的节点。私有插件节点不递归标记，不改变其角色、焦点或输入规则；插件内部语义与键盘操作仍归对应作者。现有宿主焦点、键盘许可、命令和组件生命周期继续沿用。

## 阅读和焦点

有溢出的框架阅读区提供有名称的Tab入口。方向键按40px浏览，PageUp/Down按可视高度减40px浏览，Home/End到首尾；谱面舞台使用既有谱页滚动容器。只有阅读入口自身接收这些操作，输入框、按钮和私有内容的按键不被代理。

不处理Ctrl/Alt/Meta/Shift组合、IME合成、229键码、AltGraph、已消费事件及死键。结构样稿的页签、调整把手和退出链也使用既有`isPlainKey`。不新增F6等未确认快捷键。

重绘按原ID恢复，其次按同区域、同标签、同节点类型恢复无ID控件。原目标失效时，使用该组件声明的框架内部回退；布局组件本地声明入口隐藏后接续取消、确认／取消隐藏后返回编辑入口，公共工具不写死这些ID。其余旧节点隐藏、移除或禁用时返回可见的所属区域开关。结构样稿在重绘前捕获，集成入口的框架内置布局页在自身更新前捕获；不改宿主焦点策略或第三方插件更新。程序恢复使用`preventScroll`；阅读祖先可局部调整，以免键盘目标藏在裁切区或组件声明的固定头下。普通鼠标焦点不新增蓝框，键盘阅读入口用内侧蓝轮廓，常态保持透明边缘。

### 组件本地声明（框架内部，非插件SDK）

| 属性 | 消费条件 | 失效／缺失行为 |
| --- | --- | --- |
| `data-frame-focus-fallback="目标ID"` | 捕获原框架节点时保存；原目标不可用后查找。候选须在当前root内、明确框架所有权且可用 | 私有、root外、隐藏或禁用目标不认领；回到原宿主区域开关／舞台路径 |
| `data-frame-focus-inset` | 阅读祖先查询显式标记的头部；须属于框架、可用且不包含当前目标；按头部高度加4px避让 | 无标记或不满足条件时不增加头部避让；保留容器边缘4px余量 |

布局组件用`h(..., { dataset: { frameFocusFallback: "layout-cancel" } })`声明接续，用`frameFocusInset: "true"`标记固定头部。属性由所属框架组件创建，公共工具不按其私有class查询；不递归给插件内容加标记，也不向插件开放任意目标读写。

良好场景是组件重绘后接续自己明确声明的可见控件；基础场景是未声明时沿用宿主回退；拒绝场景是声明指向私有或root外节点。回归测试以任意sample ID验证解耦、以所有权和root限制验证拒绝，浏览器检查实际落点、固定头避让与谱页矩形。错误做法是在公共工具新增“某插件按钮ID → 另一个ID”的分支。

结构样稿的右侧页面入口使用tablist/tab/tabpanel、唯一当前页签和纵向方向键／Home／End。普通开关使用aria-pressed，展开入口使用aria-expanded；装饰图形从可访问树隐藏，按钮名称继续由宿主或提供者指定。

## 可读性

复用现有辅助文字色改善关闭区域示意和普通说明，冻结的tokens/base/structure视觉声明保持。检查按实际计算前景／祖先背景／透明度计算颜色比值；启用的普通说明以4.5为本轮检查门槛。禁用操作、不可见内容和装饰占位分别记录，不将它们当成已通过的正文。

不靠颜色单独表达失败、未知、当前页或编辑状态。窗口容量、侧栏与工作台分区、谱页普通操作稳定、resize居中、隐藏滚动条及默认无动画继续原合同。

## 验证与交接

- 状态／DOM替身测试验证键盘保留、所有权、焦点恢复、阅读步进和释放，不证明像素、真实IME或读屏器体验。
- 实际浏览器验证页面与固定区首尾、页签导航、连续Tab、菜单／详情关闭、尺寸调整与统一布局确认／取消，并检查原场景和紧凑窗口。
- 正常操作谱页X/Y/宽/高保持；只有主动谱页浏览、缩放或窗口resize允许按其原合同改变可见位置。
- 可访问树检查只证明名称／角色／状态暴露。真实NVDA／Narrator、系统高对比度和Windows100/125/150/200%缩放必须单独实测，不称完整无障碍认证。
- 正式插件接入应消费既有承载和命令合同，保持自身内部界面特色；不把这份样稿内部函数作为公开服务。

错误做法：把阅读按键绑在整个插件子树；重绘后无条件聚焦首个按钮；为了显示焦点调用全页面scrollIntoView。

正确做法：只在显式阅读入口处理普通键；恢复原操作身份或可见区域开关；仅调整所属阅读容器，并实测谱页几何不变。
