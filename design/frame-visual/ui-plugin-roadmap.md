## 不变的架构边界

1. 上／下／左／右四栏属于通用承载区域；panel 属于内容身份；页签、列表、网格属于呈现。名称和图标不决定位置、尺寸或样式。当前实际组件编排仅接左右侧栏，上／下侧栏内容管理仍待后续接入。
2. 快捷键路由器与 UI 命令路由器都是 UI 包内部模块。组合根装配共享实例；业务插件贡献自己的动作和默认绑定，不把每个内部模块注册成独立平台插件。
3. 快捷键路由器选择动作，命令路由器调用处理函数。一次输入只有一次命令执行；按钮、菜单与快捷键复用动作。
4. 插件平台负责贡献所有权、固定会话和权限发放。业务转换复用类型化领域端口、应用服务与内核，不增加全局业务能力目录或 UI/Agent 共用命令总线。
5. 组件私有输入、业务选择与阅读状态不进入布局配置；布局取消不回滚谱面业务，谱面撤销不回滚侧栏样式。
   用户补充：四栏的开关、尺寸与几何排布属于日常使用，不随栏内组件取消回滚；用户名称统一为上／下／左／右侧栏。
6. 固定插件集合和单组件单实例继续保持。运行时添加已加载内容属于布局操作，不等于安装新插件。
7. 每批采用新的源码基线，保护原 design/frame、废弃产品 UI 与同期设计修改；不覆盖历史证据。

文档补充已完成，详见 [插件设计主稿第 7–9 节](./plugin-design-v0.1.md)。下一版要求所有插件共同具备稳定身份、名称、插件版本与宿主接口兼容要求；整个插件不按功能分类，在最大可选扩展集合中按需组合接口。必填为空不合法，可选贡献省略或 null 合法，全部可选贡献为空也合法；实际条目仍需满足内部必填、依赖、权限及限制。

状态：基础映射与兼容迁移完成。当前已支持稳定 id、global/component/score 声明、内存用户覆盖/取消/恢复、冲突预检、权限执行、失败清理和有效键位提示。设置界面的改键编辑器尚未接入，保存与恢复留到批次 8；视图菜单已在批次 5 接入打开期间的映射刷新，其他旧菜单和布局浮层仍在重新打开或构造时读取最新映射。

目的：把普通快捷键从组件中的硬编码移为可查询、可覆盖的声明，同时复用已有焦点保护。

首批范围：单次组合键、当前组件/谱面/全局作用域、插件默认绑定、内存中的用户覆盖/取消绑定、冲突诊断、命令可用性与权限。已确定映射描述包含稳定绑定 id、command、scope、可选 componentId、owner、defaultKeys、有效 keys 与 overridden。所有者由宿主登记身份绑定，组件目标以实际实例为准。

迁移现有 command.keys 到唯一有效映射来源。旧 keys 按全局默认绑定兼容，安装预检、失败回滚、清理和菜单快捷键提示同步迁移；commandFor 等旧接口可以委托新映射模块，不能留下两张独立维护的有效按键表。命令实现继续只有一份。

组件作用域执行沿用组件权限检查，用户改键不会新增权限；全局执行沿用宿主已登记的命令与其可用性。当前组件的绑定认领按键后，即使命令被拒绝，也不继续触发另一个全局动作。普通快捷键从 handleKeyDown 中移出，hook 保留给复杂交互，并与映射定义明确消费顺序。

推荐默认：不提供多键序列、宏、任意表达式条件和通用规则语言；不存在隐式加载顺序覆盖。不同作用域允许同键，同一有效作用域冲突可诊断。谱面作用域只在实际谱面焦点上下文中启用。

验收：改键后旧键不再生效；取消与恢复默认正确；两个组件同键仅当前实例执行；文本输入和输入法保留；权限/禁用动作不能绕过；命令执行一次；菜单提示读取有效映射；旧包和安装回滚测试通过。设置界面的改键编辑器可在映射稳定后接入，配置落盘归批次 8。

## 6. 真实谱面编辑闭环

目的：用一个真实业务操作检验框架边界，避免只用占位内容证明架构。

```text
按钮 / 映射后的快捷键 / 谱面输入
  → 记谱输入适配与编辑意图
  → 受限 ScoreEditPort
  → 类型化桌面边界
  → ScoreSessionService
  → Kernel 事务
  → 只读投影、选择与反馈
```

已有后端服务与音符事务转换路径供复用，不在 UI 包重写音乐规则。离散动作可通过共享 UI 命令 handler 薄绑定到领域控制器；连续谱面输入可以直接使用获准的类型化端口，不强迫每次输入多绕一层通用命令。

先建立新框架下的真实只读乐谱视图，再接一个限定范围的音符输入操作。首个闭环涵盖目标定位、时值/音高意图、一次原子事务、投影刷新、撤销/重做、拒绝、过期版本和重复请求处理；不同时扩展 MIDI、六线谱、播放和复杂排版。测试可以使用端口替身模拟故障，但实际验收必须运行真实服务与投影，不能将 mock 成功计为已接内核。

中央承载的前置合同同时覆盖主体视图与工作区左右固定插件区：分配独立空间、接入固定配置与生命周期，由宿主协调原左右侧栏自动收起和恢复，并保留手动调整。收放策略复用原状态所有者，触发定义与空间阈值经容量验证确定；辅助插件不自行操作全局布局。相应承载完成后增加主体与固定内容共存的测试，小面积临时菜单按第 5 批的独立就绪门槛接入，不要求先实现自由放置。

验收：按钮和快捷键复用同一音乐语义；一次输入产生一次预期事务；布局变化不改变文档版本；撤销/重做由内核负责；过期和拒绝没有假成功；谱面选中与下一输入位置按领域规则更新；只读组件不能调用编辑能力。

前置事项：选择基于备份的新桌面组合根与最小构建方式，复用现有可信宿主，不改废弃 workbench UI。它属于业务接入的一部分，不能假定 file 预览已经具有 Tauri 服务能力。
