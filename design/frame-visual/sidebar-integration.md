# 统一 panel 接入现有侧栏

2026-10-02。备份视觉副本的默认入口已连接目录、编排和呈现适配，70 项相关测试通过。UI 路由器继续是 UI 框架包内模块，没有新增独立平台插件。

## 当前实际流程

```mermaid
flowchart LR
  A[点击 AI 助手页签] --> B[UI 包内共享命令路由器]
  B --> C[更新兼容选择偏好]
  C --> D[宿主状态通知]
  D --> E[呈现适配查询 panel 与编排]
  E --> F[组件宿主按 componentId 复用实例]
  F --> G[当前侧栏更新显示]
```

这几个方框是同一个 UI 框架包中的职责模块，不是多个平台插件。音符编辑没有在本批接入；后续业务 handler 应调用受限的编辑端口，内核继续拥有文档事务与撤销历史。

## 例子：保留 AI 助手的输入

1. 点击 AI 助手页签，现有路由执行 `frame.workspace.page.select`，更新 rightOpen 和选择偏好。副本没有调用真实 AI 服务。
2. 状态通知 Shell。呈现适配从目录查到 `frame.builtin.assistant`，确认其已启用且位于右侧，选择现有页签呈现。
3. 首次可见时，组件宿主执行 mount，建立输入框。输入文字是组件自己的草稿，不因为每次按键就改宿主布局或提交内核命令。
4. 切换到音色页时，呈现适配隐藏助手内容并报告 setVisible(false)，保持原实例和输入节点。收起整个右侧栏时，仍保留当前内容的显示规则，由外层区域隐藏；实际可见性通知单独计算。
5. 切回助手或展开侧栏时，宿主继续使用原节点，文字保留。最终释放才执行实例 dispose 和 onDispose。测试使用真实内置输入框并断言节点相同、mount 为 1、输入内容保留、最终清理一次。

## 为什么这样分工

- 内容实现管理自己的输入和资源，不必了解左侧列表或右侧页签的 DOM 结构。
- 编排拥有位置、启用和顺序，呈现拥有显示规则，尺寸与窗口约束仍来自原几何服务。改一种呈现方式时，不需要重写内容或音乐业务。
- 命令处理函数直接调用状态方法，状态通知再驱动呈现；没有把通知重新变成命令、再次路由或提交第二份文档事务。
- 内容 id、表面 id 与 componentId 分工明确，旧表面别名不会被误当作另一个组件。组件宿主新增可选元素身份校验，适配释放自己的实例时不会误释放后来复用同一 id 的实例。
- currentPage 暂作选择偏好，仅保留一个权威存储。实际选中项从当前可用列表派生，避免位置、启用、选择三者互相覆盖。

## 已接入的行为

默认四个内置内容仍位于右侧、左侧为空，原内置声明、CSS、尺寸常量、图形和谱页未由本批修改。Shell 消费的是规范 panel，v1 的 modules/pages 分组仅用于兼容登记。

`frame.sidebar.panel.move/enabled/reorder` 三个内部动作绑定到已有路由，处理函数直接调用编排。内置四项仍只允许 right，非法左移被拒绝。独立测试插件声明 left/right，用实际呈现适配验证双向移动与左侧排序；移动复用元素与输入，不改变区域尺寸。

页签导航使用当前右侧内容的顺序和启用状态。选择偏好不可用时回退到第一项；全部未启用时标题为右侧栏、计数 0 / 0、翻页禁用。直接选择未启用或不在右侧的项被拒绝。点击当前实际回退项仍能折叠侧栏；翻页只改选择偏好，保留原区域展开状态。

没有增加移动/排序/启用按钮、模块库或样式选择界面，当前动作主要为已有框架接入和后续布局功能提供入口。未可见且尚未挂载的内容保持懒挂载，已挂载内容隐藏后保留实例。

## 验收与范围

当前 70 项测试通过：原 58 项回归加 12 项本批集成测试。集成测试使用实际平台、目录、状态、router、组件宿主、呈现适配和 Shell；DOM 用最小测试替身，不计算字体、浏览器布局和像素。

新旧 Shell 在 1024×720、1280×720、1440×900 三种视口参数下，对默认结构及助手选择、区域折叠、翻页、布局调整/取消的 DOM、属性、内联样式进行对照，结果一致。另验证空侧栏、回退选择、别名、左侧排序、非法命令、安装回滚、无关实例和替换实例保护，以及组件宿主最终释放。

本批起始基线包含 84 个非 evidence 文件，修改文件保留修改前副本。原框架 33 文件清单及 SHA256、保护范围、测试输出和语法结果记录在 `evidence/sidebar-integration/`。历史审计和截图不覆盖。

浏览器工具拒绝 file:// 访问，本轮未进行浏览器截图或像素对照，也没有使用其他协议或浏览器绕过拒绝。因此结构对照通过不代表浏览器视觉验收完成。当前用户已打开的预览页没有被工具操作。
