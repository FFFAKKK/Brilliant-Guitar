## 2. 签名与协作

```js
const host = createMotionCoordinator({
  adapter: createMotionAdapter(),
  mode: "full", profile: "continuous", reducedMotion: false,
  onIssue: error => { /* 局部诊断；不改变操作结果 */ },
});

// descriptor 与节点许可由可信宿主绑定，插件不能在请求中冒用身份。
const local = host.bind({
  plugin: { id: "frame.layout", label: "工作区布局", version: "0.1.0", hostApiVersion: "motion-review/2" },
  root: localRoot,
  // 作者定义；此处为精简示例，布局实际定义还包括选择标记和三套变体。
  animations: {
    "content-transition": { defaultVariant: "continuous", variants: {
      continuous: { type: "tween", duration: .25, fadeDuration: .16, exitDuration: .08, ease: [.23, 1, .32, 1] },
    } },
    "drag-settle": { defaultVariant: "continuous", variants: {
      continuous: { type: "spring", stiffness: 260, damping: 32 },
    } },
  }, // null 或省略合法；获准目标使用静态结果
  targets: {
    content: { node: contentNode, intents: ["content-transition"] },
    item: { node: itemNode, intents: ["drag-settle"] },
  },
});

local.play({ intent: "content-transition", target: "content", to: { x: 0, y: 0, opacity: 1 } });
local.hold({ intent: "drag-settle", target: "item" }); // 冻结当前呈现，取得只读位置
local.place({ intent: "drag-settle", target: "item", to: { x: 0, y: 32 } }); // 直接操控
local.play({ intent: "drag-settle", target: "item", to: { x: 0, y: 0 }, velocity: { y: 300 } });
local.dispose(); // 释放该实例，其他实例继续运行
host.setPolicy({ mode: "none" });
host.dispose();
```

播放返回 `{ finished: Promise<{status}> }`。状态为 `completed`、`interrupted`、`cancelled` 或 `engine-failed`。这个 Promise 只表示表现结果，不决定布局提交。身份、节点、具体引擎和参数许可不通过播放请求暴露。

协作顺序：作者模块提供定义；可信组合根/局部挂载把定义和宿主节点许可一次绑定；绑定校验并复制不可变快照。组件先更新当前内容／排列，再在原节点上消费局部端口；宿主在作者提供的变体中选择，套用系统策略；适配器按定义的 tween/spring 执行，失败或停用保留已接受状态。请求指定的 profile 未被该动作声明时，使用作者的 defaultVariant，不凭空生成效果。

动画类型只开放 `tween`、`spring`、`instant`。内容的透明度轨道仅由 tween 执行；内容也可声明 instant，选择/排序可选择任一类型。每个动作必须有合法的 defaultVariant 和 1–8 个 variants；变体名为 1–40 字符的小写字母、数字、连字符，首位字母。tween 的 duration/ease 必填，内容另外必填 fadeDuration/exitDuration；spring 必填 stiffness/damping；instant 只接受 type。秒数每项 0.04–0.30，Bezier 四项有限且在 0–1，stiffness 80–800、damping 10–80。未知字段、缺失值、越界、稀疏曲线均拒绝；这些是试点预算，不是所有未来效果的正式上限。

## 3. 执行合同

- 基础声明的 id、label、version、hostApiVersion 必须合法；可选 animations 为 null / undefined / {} 时为空，不生成默认动画能力。宿主目标许可独立于可选美术定义，未定义的获准动作即时到达合法静态终态；未获准目标仍拒绝。
- 目标必须是局部 root 的后代，不能是 root 本身，不能跨实例重复占用；每次操作重检实际归属。目标许可来自宿主，插件不提交任意节点或选择器。
- 内容转场只允许数值 x/y（±24px）及 opacity（0–1）；选择标记只允许 x/y（±256px）；拖动吸附只允许 x/y（±512px）。位置必须有限；松手速度限定 ±1600px/s。这些是试点限值，尚未发布正式预算合同。
- 不接受 width/height、任意 CSS、外壳目标、pluginId、duration、easing、并发设置等请求字段。所有模式先校验，再执行；关闭动效不能绕过限制。有效 0 保留。
- 作者决定具体曲线、弹簧、时长；宿主执行完整／慢放／减少／关闭策略。系统减少动效优先于页面完整播放；设置变更先让已有动作到达已接受结果。
- 布局作者保持原效果：连续内容位移 250ms、显现 160ms、退场显隐 80ms；聚焦对应 260/200/100ms，静稳对应 140/140/70ms。选择标记沿 `cubic-bezier(.77,0,.175,1)` 接续，静稳即时；拖动连续/聚焦使用 stiffness=260、damping=32，静稳使用 500/46，适配器 mass=1。具体参数在绑定时声明和校验，每次播放仍不能临时自传 timing。慢放按 2.5 倍观察，弹簧参数同步缩放，不作为默认节奏。
- 选择呈现的当前实现：局部 SVG clipPath 的 rect 是已绑定 selection 目标，原 x/y 请求和端口不变；同一个窗口裁剪蓝色背景及 aria-hidden 的亮色文字副本。原按钮基础文字保持普通色，不由 aria-selected 立即变色。副本文字从原按钮取得，字体、padding、line-height 和实际几何一致，无复制按钮或焦点目标；每实例 mask/tab/tabpanel ID 唯一。
- 减少动效时内容的 from/to x/y 都归零，只保留 100ms 透明度转场；选择标记和排序落位即时。不能只让 from 等于非零的退场 to，那会产生瞬间偏移。静稳风格的标记也即时切换。
- 后续内容目标从实际当前位置接续；捕获旧/新页面的呈现后才改变 aria-hidden/inert，避免 CSS 先把运动重置。业务当前页已即时更新，旧页面不会成为焦点目标。
- 拖动采用真实 Pointer Capture，直接跟随指针。松手提交顺序，保留节点，再通过 Motion 的数值弹簧到达已接受槽位。键盘排序即时执行；Escape、pointercancel、失去捕获和页面隐藏取消拖动。
- 拖动经过新槽位时，其他项通过局部端口提前让位，但 DOM 顺序和业务顺序都保持；槽位取布局 offsetTop，不取已动画位移的视觉位置。反向移动接续到原槽，释放才提交；取消会清除所有预览位移，落位期间可再次抓取。
- 释放速度按受约束后内容的实际位移计算，不能读取超出排序区域的原始指针路径。本布局样稿将速度投影到落位方向，并以剩余距离 / 120ms 限制惯性；已经到槽位时为 0，远离槽位的速度为 0，朝向槽位的合法速度保留到该上限。布局样稿持有排序几何，引擎和通用端口不新增边界或布局知识；数值弹簧仍从实际位置接续。
- 每个实例持有独立的活动目标映射。新请求中断同目标旧动作；旧完成/失败回调经过记录身份检查，不得改写新动作。
- 实例释放取消播放、恢复原局部内联表现、释放节点许可与事件。重复释放安全；宿主最终释放全部实例。局部故障或诊断失败不改变业务状态。

当前底层分工：内容转场通过 **Motion mini 原生 DOM 播放**（完整 transform 和 opacity 的独立轨道）；选择标记用相同适配器播放完整 transform；拖动与让位通过 **Motion 数值弹簧**保留释放速度，每个局部节点单独写完整 transform。不动画化布局属性。数值弹簧的更新仍需 JS 主线程，不能把它宣传成无主线程成本；大规模同时拖动/绘制还需要单独测量。

## 4. 校验与错误矩阵

| 条件 | 行为 |
| --- | --- |
| 必填声明为空、版本无效、试点 API 不匹配 | 绑定失败，不取得资源 |
| 可选动画为空；或获准动作未提供定义 | 合法，无引擎轨道；有目标时即时静态呈现 |
| 已提供定义非法、默认变体缺失、参数越界、未知字段 | 绑定失败，校验结束前不捕获表现或占用节点，不能静默过滤为空 |
| 修改已绑定的原定义对象/曲线 | 不影响已复制的执行快照 |
| 选定风格在某动作中未提供 | 使用该作者声明的默认变体 |
| 目标属于外壳／其他实例，或实际已移出 root | 明确拒绝；不调用引擎 |
| 未知字段、非法数值、范围超限 | 所有播放模式均拒绝；DOM 不变 |
| 连续反向切换 | 中断旧运动，从当前位置转向新结果 |
| 中途关闭／减少动效 | 立即达到已接受静态位置；后续按新策略执行 |
| 引擎同步或异步失败 | 标明 engine-failed，使用已接受的静态目标 |
| 旧动作迟到完成／失败 | 不写回新动作 |
| 实例卸载或页面最终退出 | 清理监听与动作，其他实例不受影响 |

## 5. 正确、基本与错误用法

- 正确：布局样稿提交顺序后，用局部 `drag-settle` 到达零偏移；读取真实松手速度。
- 基本：没有动画贡献的组件继续正常显示，不占用默认动画目标。
- 错误：让动画结束回调提交布局、插件直接请求谱面节点，或关闭动效时直接 Object.assign 任意样式。

未来独立风格提供者仍应由同一插件平台、启动选择和生命周期装配；此次不新增动画注册器、热切换贡献拓扑或正式能力目录。
