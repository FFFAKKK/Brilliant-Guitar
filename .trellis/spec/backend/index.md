# Reserved Backend Guidelines

> This layer is reserved for future non-kernel application/backend services.

---

## Status

Reserved. Do not use this layer for `Pure Core Kernel V1`.

Current Core Kernel implementation must use:

- `../core-kernel/index.md`
- `../core-kernel/backend/index.md`

---

## When This Layer Becomes Active

Fill this layer only after the project creates non-kernel backend or service code, such as persistence services, import/export workers, update services, diagnostics packaging, cloud sync, account services, or other application-level services.

Until then, this layer intentionally contains no active coding rules.
