# REQ-005 播放校对、练习与音频能力

## 决策状态

- 状态: 已确认 MVP 最小播放校对。
- 合并目标: 最终 PRD 的播放校对、练习和音频能力范围。
- 当前结论: 第一实现阶段只做最基本播放校对，包括合成播放、开始/暂停/继续/停止、播放光标、节拍器、基础速度控制，以及从文档快照生成播放事件。
- 明确后置: 真实采样音色、音频轨、混音、音频导出、真实录音同步、视频同步、DAW 级音频能力、复杂技巧音色模拟。
- 开放问题: 无。播放校对范围已经按用户选择收敛。

## 用户价值

用户写谱后需要立即听到节奏、音高和输入结果，快速发现错拍、错音、漏音、错误时值或错误小节结构。MVP 播放不是完整练习系统，也不是 DAW；它服务于“写完 4 小节 riff 后能可靠校对”的编辑闭环。

## MVP 播放校对范围

- REQ-005-F01: 用户可以播放 4 小节标准 6 弦吉他谱。
- REQ-005-F02: 用户可以从谱面开头播放，也可以从当前编辑光标所在位置播放。
- REQ-005-F03: 用户可以执行开始、暂停、继续和停止。
- REQ-005-F04: 播放过程中谱面必须显示播放光标或当前 beat/note 高亮。
- REQ-005-F05: 播放必须读取谱面 tempo，并支持基础速度控制。第一阶段可使用 50%、75%、100% 这类固定倍率，或等价的最小可测倍率集合。
- REQ-005-F06: 播放必须支持节拍器开关。
- REQ-005-F07: 播放事件必须从文档快照生成，不能从 SVG、VexFlow 对象或 React 组件状态反推。
- REQ-005-F08: 第一阶段可使用基础合成音色或占位吉他音色，不追求真实采样。
- REQ-005-F09: Core Loop 技巧在第一阶段可以近似播放或不产生特殊音色，但技巧数据不得被删除、改写或忽略保存。

## 播放事件契约

播放事件是播放层消费的只读数据，不是谱面真相数据。

每个播放事件至少需要表达:

- 稳定事件 ID。
- 来源领域对象 ID，例如 note、beat、measure 或 metronome tick。
- 开始时间。
- 持续时间。
- 事件类型: 音符、休止、节拍器 tick 或内部同步事件。
- 音高或静音信息。
- 轨道 ID。
- 可选显示同步目标，例如当前 beat 或 note 的布局 primitive ID。

## 行为契约

- 播放层只读文档快照，不得直接修改谱面文档。
- 播放、暂停、继续、停止、速度变化和节拍器开关不得创建 undo/redo 命令。
- 播放失败不得导致文档脏状态变化，不得破坏当前编辑选择。
- 速度变化必须保持播放时间和 UI 高亮一致。
- 播放光标必须基于稳定领域 ID 或布局 primitive 映射，不得依赖 VexFlow 内部对象作为唯一真相。
- 文档在播放期间被编辑时，第一阶段可以停止播放并提示需要重新播放；不要求热更新播放队列。

## 后置练习能力

以下能力有产品价值，但不是第一阶段阻塞项:

- 选区循环播放。
- count-in。
- 小节范围循环。
- 视觉指板显示正在播放的弦和品。
- 可保存练习片段。
- 多轨聚焦。
- track mute/solo。
- 变速练习曲线。

## 后置音频能力

以下能力后置到播放校对闭环稳定之后:

- 高真实度吉他采样音色。
- 贝斯、鼓、键盘等多乐器播放验收。
- 音频轨导入。
- 真实录音或视频多点同步。
- 波形视图。
- 多 stem 混音。
- 合成播放与真实录音混合。
- 音频导出。
- VST 或第三方音源宿主。

## MVP 不做

- 不做 DAW 级音频编辑。
- 不做 VST 插件宿主。
- 不做实时录音、多轨混音或音频母带能力。
- 不做贝斯、鼓、键盘多轨播放作为第一阶段验收门槛。
- 不做 track mute/solo 作为第一阶段验收门槛。
- 不做真实录音或视频同步作为第一阶段验收门槛。
- 不做音频导出。
- 不把循环、count-in 或虚拟指板作为第一阶段阻塞项。
- 不要求 Core Loop 技巧有高仿真音色效果。

## 验收标准

- [ ] AC-005-01: 用户可以播放一段 4 小节标准 6 弦吉他谱，并听到基础音高与节奏反馈。
- [ ] AC-005-02: 用户可以暂停、继续和停止播放。
- [ ] AC-005-03: 播放时谱面光标或当前 beat/note 高亮与声音进度同步。
- [ ] AC-005-04: 用户可以打开或关闭节拍器。
- [ ] AC-005-05: 用户可以使用 50%、75%、100% 或等价的基础速度控制。
- [ ] AC-005-06: 播放事件由文档快照生成，播放层不修改文档，不创建 undo/redo 命令。
- [ ] AC-005-07: 带有 Guitar Domain 正式首批技巧样例的谱面可以生成播放事件；技巧音色可简化，但版本化领域语义不得丢失。
- [ ] AC-005-08: 第一阶段验收不要求贝斯、鼓、键盘、音频伴奏、视频同步、真实采样、音频导出、track mute/solo 或 DAW 能力。
