# REQ-006 导入导出与格式兼容

## 决策状态

- 状态: 已按 MVP 跑通优先级收缩范围，第二阶段 Guitar Pro 导入范围已确认
- 合并目标: 最终 PRD 的文件兼容和互操作要求
- 当前结论: 第一实现阶段必须支持原生 `.bgp` 打开/保存和 PDF + PNG 导出；第二阶段只做 Guitar Pro 导入；MusicXML、MIDI、文本六线谱、SVG、PDF/图片识别和 Guitar Pro 导出继续后置。
- 已确认决策: Guitar Pro 导入只面向用户本地文件，采用 best-effort 导入，不做导出，不碰 mySongBook、云曲库或受保护内容。

## 用户价值

工业级开源打谱软件不能成为孤岛。用户需要导入已有素材、导出给学生/乐队/客户，并在必要时与其它音乐软件交换数据。

## 第一实现阶段打开能力

第一实现阶段必须支持:

- 打开本项目原生 `.bgp` 文件。
- 打开自动保存恢复文件或由应用生成的备份文件。
- 打开失败时给出明确错误原因，不静默丢弃数据。

第一实现阶段不把外部格式导入作为验收门槛。原因是当前最高优先级是跑通新建、编辑、播放校对、保存、重开和 PDF/PNG 导出闭环。

## 第二阶段导入

第二阶段只做:

- Guitar Pro 格式导入，需先做格式和授权风险评估。

### 第二阶段 Guitar Pro 导入范围

- 只导入用户显式选择的本地 Guitar Pro 文件。
- 不抓取、不登录、不同步 mySongBook、云曲库或任何受保护内容。
- 不实现 Guitar Pro 格式导出。
- 优先覆盖当前 `.gp` 文件。
- 常见历史 `.gp5` / `.gpx` 只在合法样例和解析方案稳定时覆盖可控子集。
- 不承诺完整兼容所有历史 Guitar Pro 文件。
- 不支持或不能可靠映射的轨道、技巧、排版、音色、自动化和音频轨必须写入 `ImportReport`。
- 导入结果必须进入 `.bgp` 领域模型并通过文档验证器。

第二阶段之后再评估:

- MusicXML。
- MIDI。
- ASCII tab 或纯文本六线谱。
- PDF/图片识别，不建议作为第一版核心。

## 第一阶段导出

第一实现阶段必须支持:

- 原生文件格式。
- PDF。
- PNG。

后置导出:

- SVG。
- MusicXML。
- MIDI。
- ASCII tab。
- MP3/WAV/FLAC/OGG 音频。
- Guitar Pro 格式导出，长期后置，不进入第二阶段。
- 教学网页包。
- 视频素材或动态谱面导出。

## 兼容原则

- 导入必须产出明确的兼容报告，不能静默丢数据。
- 导出必须声明支持范围，例如技巧是否保留、音色是否保留、布局是否保留。
- 对非开放格式，必须把法律和逆向风险列为产品风险，而不是默认可做。
- 格式转换必须经过文档验证器，不能把非法谱面写入原生模型。

## 行为契约

- 导入流程输出 `ImportReport`，至少包含成功项、警告、丢失项、无法识别项。
- 导出流程输出 `ExportReport`，至少包含目标格式、保留能力、降级能力、失败原因。
- 导入导出不得绕过核心文档模型。
- 批量转换能力后置，但架构不能阻碍未来实现。

## MVP 不做

- 不把 MusicXML、MIDI、ASCII tab 或 Guitar Pro 导入作为第一阶段验收门槛。
- 第二阶段不把 MusicXML、MIDI、ASCII tab、PDF/图片识别或 Guitar Pro 导出作为验收门槛。
- 不承诺完整兼容所有历史 Guitar Pro 文件。
- 不承诺 PDF/图片自动识谱达到生产可用。
- 不承诺导出文件在所有第三方软件中完全一致显示。
- 不把 SVG 导出作为第一阶段验收门槛。

## 验收标准

- [ ] AC-006-01: 用户能打开由当前版本保存的 `.bgp` 文件，且谱面、元数据、技巧和布局基础信息不丢失。
- [ ] AC-006-02: 导出 PDF 后，标题、轨道名、小节、六线谱和基础技巧可读。
- [ ] AC-006-03: 导出 PNG 后，标题、轨道名、小节、六线谱和基础技巧可读。
- [ ] AC-006-04: 第一阶段导入不要求 MusicXML、MIDI、ASCII tab、PDF/图片识别或 Guitar Pro 格式。
- [ ] AC-006-05: 第一阶段导出不要求 SVG、MIDI、MusicXML、音频或 Guitar Pro 格式。
- [ ] AC-006-06: 后续新增任何外部导入格式时，必须输出 `ImportReport`，报告成功项、警告、丢失项和无法识别项。
- [ ] AC-006-07: 第二阶段 Guitar Pro 导入必须先定义支持的文件版本、能力映射表、降级规则和合法 fixture 来源。
- [ ] AC-006-08: Guitar Pro 导入器处理不支持能力时，必须在 `ImportReport` 中说明丢失项、降级项和无法识别项。
- [ ] AC-006-09: Guitar Pro 导入器不得读取 mySongBook、云曲库、受保护内容或用户未显式选择的文件。

## 开放问题

- 无。第二阶段 Guitar Pro 导入采用用户本地文件 best-effort 范围；具体解析库和合法 fixture 来源在第二阶段技术研究中确认。
