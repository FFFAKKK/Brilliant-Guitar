# REQ-004 五线谱、六线谱与排版同步

## 决策状态

- 状态: 草案
- 合并目标: 最终 PRD 的显示、排版和同步要求
- 当前结论: 第一实现阶段必须支持六线谱与基础五线谱同步，节奏范围只覆盖 4/4、单 voice、固定 tempo、四分/八分/十六分、基础休止和单音输入；不支持歌词、和声分析、罗马数字或简谱；排版目标先满足基础教学/创作交流，不追求出版级雕版。
- 关键开放问题: 无。MVP 和弦、歌词、和声分析、罗马数字和简谱能力已确认后置。

## 用户价值

吉他手常用六线谱，但教学、出版和跨乐器协作经常需要五线谱或节奏谱。产品必须让同一段音乐在不同视图间保持一致，避免用户维护两套冲突数据。

## 核心原则

- 音乐事件是事实来源。
- 五线谱、六线谱和节奏谱是同一数据的不同视图。
- 排版信息可以保存，但不能改变音乐语义。
- 任何视图编辑都必须同步到其他视图。

## MVP 显示模式

- REQ-004-F01: 六线谱单独显示。
- REQ-004-F02: 五线谱单独显示。
- REQ-004-F03: 五线谱 + 六线谱组合显示。
- REQ-004-F04: 第一阶段不要求独立节奏谱或 slash notation；只要求六线谱和基础五线谱同步。
- REQ-004-F05: 每轨可以配置默认显示模式。
- REQ-004-F06: 用户可以在不破坏数据的情况下切换显示模式。
- REQ-004-F07: 第一实现阶段的五线谱以基础音高、四分/八分/十六分节奏、休止和小节显示为主，不承诺出版级细排版。

## MVP 排版能力

- 小节自动换行。
- 手动系统换行。
- 页面边距。
- 谱号、拍号、调号显示。
- 小节编号。
- 简单段落标记，可选。
- 打印/PDF 友好布局。

第一实现阶段优先级:

1. 六线谱可读、可编辑。
2. 五线谱基础音高和节奏正确。
3. 六线谱和五线谱在同一音乐事件上同步。
4. PDF/图片导出可用于教学和创作交流。
5. 出版级雕版细节后置。

## 同步行为

- 在六线谱修改品号时，五线谱音高必须跟随当前调弦更新。
- 在五线谱修改音高时，六线谱必须尝试保留原弦；如果不可行，给出可选指法。
- 修改四分/八分/十六分时值和基础休止时，所有视图必须一致。
- 附点、三连音、跨小节延音线、多声部同轨和变拍号后置；第一阶段遇到这些输入应返回明确 unsupported。
- 移调操作必须同时更新音高和可用指法。
- capo 变更必须明确是改变实际发声、显示指法，还是两者都变。

## MVP 不做

- 不追求第一版达到 Finale/Dorico 出版雕版质量。
- 不做复杂交响乐总谱排版。
- 不做独立页面设计软件。
- 不做其它乐器的专用记谱视图作为第一阶段目标。
- 不做独立节奏谱或 slash notation 作为第一阶段验收门槛。
- 不做附点、三连音、跨小节延音线、多声部同轨或变拍号作为第一阶段验收门槛。
- 不做和弦名、和弦图或和弦的五线谱/六线谱显示验收。
- 不做歌词、自由文本框、和声分析、罗马数字或简谱。

## 验收标准

- [ ] AC-004-00: 同一段吉他旋律在六线谱和五线谱中显示为同一音乐事件，修改任一视图后另一视图同步更新。
- [ ] AC-004-01: 六线谱输入 C 大调音阶后，五线谱显示正确音高。
- [ ] AC-004-02: 五线谱升高某个音后，六线谱能给出至少一个合法弦/品选择。
- [ ] AC-004-03: 切换显示模式不会丢失技巧、节奏或指法。
- [ ] AC-004-04: 导出 PDF 前的页面预览与导出结果在小节换行和标题信息上保持一致。

## 开放问题

- 无。第一阶段不支持歌词、和声分析、罗马数字和简谱；只保留元数据和可选简单段落标记。
