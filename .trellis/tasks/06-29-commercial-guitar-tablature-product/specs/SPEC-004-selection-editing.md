# SPEC-004 光标、选区与键盘编辑

## 状态

- 状态: 已确认键盘优先方向与输入模型。
- 来源需求: `REQ-003-guitar-tab-editing.md`、`REQ-008-editor-workflow-ux.md`。
- 适用范围: 第一阶段 4 小节标准 6 弦吉他 riff 的核心编辑体验。

## 目标

编辑器必须让用户以键盘为主路径完成专业打谱软件的最小编辑闭环。鼠标可以辅助定位和选择，但不能成为第一阶段核心路径的前置条件。

## MVP 能力

- 支持谱面光标，光标至少能定位到小节、beat、弦和音符槽位。
- 支持键盘移动光标。
- 支持键盘输入和修改四分/八分/十六分、等长休止、弦号、品号。
- 支持时值键切换当前输入时值。
- 支持数字键输入或修改当前弦上的品号。
- 支持方向键在弦间和拍间移动。
- 支持键盘删除当前音符或选区。
- 支持 undo/redo。
- 支持复制、粘贴和基础选区编辑。
- 支持通过键盘快捷键或命令面板添加 3 个 Core Loop 技巧: `slide`、`bend`、`vibrato`。
- 支持鼠标点击定位和选择音符、小节或范围。
- 支持播放校对快捷键。

## 强制规则

- 键盘输入必须转换为语义命令系统调用，不得由 React 组件直接修改谱面文档。
- 每个修改谱面的键盘动作必须可撤销、可重做、可命令回放。
- 快捷键必须绑定稳定 command id，不得直接绑定临时 UI 回调。
- 光标和选区状态必须能映射到稳定领域对象或布局 primitive，不得依赖 VexFlow 内部对象作为唯一真相。
- 光标移动、选区高亮、鼠标拖选和编辑模式变化属于 `Editor Session Service`，不得作为 Core Kernel 文档事件发布；如果需要通知 UI，使用外部 session event。
- 非法品号、非法弦号、非法粘贴目标必须给出可定位错误。
- 同一 beat 输入多个音符、和弦图或和弦名时必须给出明确 unsupported，并保持文档不变。
- 第一阶段核心路径不得依赖 MIDI 设备、虚拟指板或移动端触摸输入。

## MVP 不做

- 不做 MIDI 设备输入。
- 不做实时 MIDI 录入。
- 不做 MIDI 文件导入。
- 不做虚拟指板点选输入作为第一阶段验收门槛。
- 不做移动端触摸优先输入。
- 不做自由文本谱解析作为已确认主输入模型。
- 不做附点、三连音、跨小节延音线、多 voice、变拍号或小节级 tempo 变化作为第一阶段输入能力。
- 不做同 beat 多音叠加、和弦图编辑器或和弦名输入作为第一阶段输入能力。

## 已确认输入模型

- 谱面光标定位到小节、beat、弦和音符槽位。
- 时值键用于切换当前输入时值。
- 数字品号输入用于当前弦/当前音符槽位。
- 方向键用于在弦间和拍间移动。
- 技巧快捷键和命令面板用于添加 Core Loop 技巧。
- 自由文本谱解析、MIDI 输入和虚拟指板点选输入不属于第一阶段主输入模型。

## 测试要求

- 键盘-only 测试必须能新建标准 6 弦吉他谱并输入 4 小节 riff。
- 键盘-only 测试必须覆盖四分/八分/十六分、弦号、品号、休止、删除、撤销/重做和播放校对。
- 键盘-only 测试必须覆盖 3 个 Core Loop 技巧的添加入口。
- 命令回放测试必须复现键盘输入产生的谱面结果。
- 非法输入测试必须验证错误定位和文档不变性。
- 非法输入测试必须覆盖同 beat 多音、和弦图或和弦名输入返回 unsupported。
