# Planning Snapshots

This directory stores reviewed planning snapshots for major project stages.

These files are historical records only. They are not the active Trellis execution entry. The active plan remains:

- `../prd.md`
- `../design.md`
- `../implement.md`

Use a snapshot to compare how a stage was approved, explain planning history, or restore context during review. Do not treat a snapshot as the source of truth for current implementation.
