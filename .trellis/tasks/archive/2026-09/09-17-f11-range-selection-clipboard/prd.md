# F11 范围选择与剪贴编辑

## 目标

让用户能在谱面中选择同一小节、同一声部内连续的音符或休止符，并通过鼠标和键盘复制、剪切、插入式粘贴。它是谱面工作区的交互能力，不是新的停靠组件。

## 要求

- 范围仅覆盖单谱表、单声部、单小节中连续的事件，包含音符和休止符。
- `Shift + 单击` 建立或扩展范围；`Shift + ←/→` 从当前选中事件扩展或收缩范围；`Esc` 清除范围。
- `Ctrl/⌘ + C` 复制、`Ctrl/⌘ + X` 剪切、`Ctrl/⌘ + V` 粘贴。
- 粘贴始终在当前编辑位置后插入，不覆盖或替换既有事件；保留事件顺序、时值、休止符/音符、书写音高和变音记号，但绝不复用源事件或音符 ID。
- 剪贴操作通过现有 Workbench Host 与 Core Command Bus 执行。浏览器剪贴板权限失败时保留当前 Workbench 会话内存剪贴板。
- 选区使用独立、轻量的半透明谱表范围带，不能复用输入光标、单事件选择框、悬停预览或播放头。
- 不因粘贴可能造成超拍而拒绝操作；沿用内核已有的轻量规则警告。

## 非目标

- 跨小节、跨声部、跨谱表选择。
- 自动覆盖、替换、合并或自动重排已有事件。
- Tauri 原生剪贴板和跨应用富格式互操作。
- 吉他谱、技巧、和弦及其他高级事件的复制语义。

## 验收标准

- [ ] 鼠标和键盘都能建立、调整并清除连续范围，且范围与缩放后的谱面事件准确对齐。
- [ ] 复制、剪切、粘贴保留所选事件的音乐内容与顺序，并产生新的事件/音符标识。
- [ ] 剪切和粘贴支持撤销、重做，粘贴不会静默覆盖已有事件。
- [ ] 浏览器 Clipboard API 不可用或被拒绝时，当前会话内仍可完成复制、剪切、粘贴。
- [ ] 范围端点无效、文档版本冲突或 Core 拒绝时，沿用现有工作台反馈，不损坏当前选择或谱面。
- [ ] Workbench 类型检查、测试和生产构建通过。
