# 独立 Agent

Node 宿主 + 简单 React 聊天界面，可脱离 Brilliant Guitar、Workbench、Tauri 和乐谱内核启动。与软件共用 `packages/agent-runtime` 中的 Pi 决策适配和 Controller。

要求 Node.js >= 22.19。在仓库根目录首次安装：

```powershell
npm --prefix packages/agent-runtime ci
npm --prefix apps/agent ci
npm run agent:dev
```

打开终端显示的本机地址，默认 `http://127.0.0.1:8787`。生产构建和启动：

```powershell
npm run agent:build
npm run agent:start
```

这些命令不会启动软件或构建乐谱内核。端口可通过 `npm --prefix apps/agent run start -- --port 8789` 指定。

在“设置”中选择 DeepSeek 或其他 OpenAI 兼容服务，填写服务地址与 API Key，点击“获取模型”后从供应商列表选择，也可手动填写自定义模型 ID。获取模型可在保存/启用之前进行，只读取供应商`/models`元数据；不保存草稿或启用Agent。服务地址包含供应商完整API前缀，例如兼容接口的`/v1`；查询保留该前缀。接口不支持或列表为空时使用自定义输入。

选择模型并保存后，手动启用 Agent。主动“测试连接”会请求生成；只打开页面、输入、保存配置和密钥不会请求供应商。DeepSeek 使用 Chat Completions，第一版关闭 thinking。获取列表不代表每个模型支持全部工具能力，可另行测试连接。

设置支持命名连接、新建/切换/删除，分别保存服务地址、模型和最近5个模型；供应商列表支持搜索。公共设置与上次选择保存在宿主数据目录，重启后恢复，但Agent仍需手动开启。

密钥默认只在当前 Node 进程内使用。Windows下可勾选“记住此连接的密钥”，由宿主使用当前用户DPAPI保护后保存；取消勾选并保存会移除密文，当前内存密钥仍可使用。其他平台暂不支持记住密钥。更换某个连接的服务地址或类型会清除其旧密钥并停用Agent；切换连接只使用该连接自己的密钥。浏览器不向模型服务直接请求，也不使用localStorage存储凭据。密文无法在当前用户下恢复时需要重新填写，不会静默复用别的连接。

默认数据目录是启动工作目录下`.agent-data`；以上根命令通过npm进入本包，通常位于`apps/agent/.agent-data`。可显式指定：

```powershell
npm --prefix apps/agent run start -- --data-dir ../../.agent-data --port 8789
```

同一数据目录只允许一个宿主使用。写入失败保留原配置；文件损坏或版本不支持时明确失败并保留文件。`.agent-data`是本地用户数据，不进入Git。

Enter 发送，Shift + Enter 换行。左侧会话列表支持新建、切换、重命名、按名称搜索、归档与恢复；窄窗口通过标题栏的会话按钮打开。新会话取消旧请求，旧记录仍保留。运行期间先停止，再切换会话。模型设置是宿主当前配置，切换会话不会自动更换服务或密钥。

完整聊天记录与会话选择保存于同目录`sessions.json`。刷新/宿主重启可恢复，失败和停止的部分内容也保留；重启时未完成的回复标记“中断”，不会自动生成或重放工具。完整记录与模型记忆分别管理：默认仅最近16轮成功对话参与上下文，超过token预算再整轮省略；较早记录仍可阅读。第一版最多200个会话、每会话4096条消息、文件16MiB，达到上限会明确失败，已有内容不会静默清除。

模型请求前先保存本轮记录，回复结束后再次保存；流式中途约每250ms合并保存。若磁盘写入失败，页面保留内存内容并显示尚未保存，可以点击“重试保存”。聊天内容是本机JSON数据，不是加密备份；API密钥仍只经独立的凭据保护链保存。会话文件不包含模型配置密钥或Controller执行恢复授权。

Agent回复支持Markdown、表格、列表、代码块及消息/代码复制；用户消息按原文显示。回复中的HTML不执行，图片只显示文字说明。软件内乐谱工具仍由软件宿主注册。

输入框上方的“添加文本”支持用户选择 UTF-8 TXT/MD，每份最多32KiB、当前会话最多3份。添加后显示文件名、大小和移除按钮。发送“读取这份资料并解释……”后，Agent可以通过`resource.read-text`读取真实内容。上传只提供资源目录，不会自动调用模型或把全文塞进模型输入。

资料是当前会话的临时不可变快照，刷新页面仍可读取；切换/新建会话或退出宿主后移除，重新选择文件才能获得新内容。运行期间不能添加或移除。工具按Unicode字符分页，最多4096字符、完整结果JSON最多12KiB；`nextStart/eof`说明实际读取范围。资料文字不能自行改变任务规则。

工具仍由同一个Controller校验和执行。Pi在真实结果返回后用`continue()`继续决策；调用ID、参数、执行结果和来源成组回放，不重复塞入普通资料。必需反馈超预算时停止下一次模型请求。界面卡片展示本次Run的开始、完成、失败及取消；折叠详情包含调用身份和时间。资源与活动不进入聊天文件，恢复聊天不会重新执行工具。完整活动历史和自动重试仍留后续。

M3.0默认Pi插件提供版本化基础职责。成功历史按真实user/assistant角色装配，当前问题只出现一次；资料、运行状态和工具结果保留来源、作用域和版本。模型配置仅作为路由信息，不证明底层模型身份。

每次请求发送前检查完整消息和工具定义的输入预算，默认8192估算token；必要时整轮省略最早的可选成功历史，并通过已有“省略历史”提示反馈。估算采用UTF-8序列化字节及消息开销，不是供应商tokenizer或实际usage。必需内容仍超预算时不会发送模型请求，页面显示预算不足。完整聊天记录继续保留。

`GET /api/model-input`提供当前会话最近一次请求的只读诊断：职责版本、角色序列、历史保留/省略、来源元数据、预算、输出上限和超时。不包含消息全文、服务地址、请求头或密钥；新请求未装配、新建/切换会话后返回null，连接探测不会覆盖聊天诊断。读取这个接口不会请求供应商。

M3.1宿主快照升级为v4，新增资料目录和本次工具活动；服务器与客户端需一起更新。连接文件v1、聊天文件v1、通用决策与External Agent Protocol v1保持原格式。

`npm run agent:typecheck`、`npm run agent:test` 验证公共合同、Pi 传输、HTTP/SSE 和本地模型 fixture。`npm --prefix apps/agent run smoke:fake` 运行明确标注的本地测试宿主，不调用真实服务。真实 DeepSeek 验收需要用户在 UI 自行填写密钥并提交请求。

构建后可在本包运行`node --experimental-strip-types test/smoke-resources.ts --port 8791`，检查真实文件入口与读取卡片。此入口只连接本机模型fixture，设置中填写任意测试用字符串，再手动启用；回答明确标注机制演示。`--client-dir dist/m31/client`可指定隔离构建目录。

Windows 本地 file 依赖使用 `.npmrc` 中的 `install-links=true`，避免需要创建符号链接。构建脚本先构建运行包并同步安装副本。若默认 npm cache 不可写，可用 `--cache <可写目录>` 指定安装缓存。
