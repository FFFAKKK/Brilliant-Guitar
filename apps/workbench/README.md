# 工作台

当前入口是 `WorkbenchApp`，展示暗色共享停靠框架、A4 五线谱、音符控制、谱面缩放和编辑历史组件。此前的完整编辑器保留在未挂载的 `ScoreEditorWorkbench`，其余组件逐个审核后装配。下方 C03–C07 内容是早期实现记录，不代表当前页面已启用所有历史功能。

## 当前接入：2026-09-15

- `UiComponentHost` 只提供组件位置、呈现方式、实时尺寸和焦点等公共逻辑；`StaffView` 自己绘制纸面，不添加统一标题栏、工具条或卡片。
- 首次进入新的宿主工作区，通过现有会话接口创建一个小节的未保存空白谱；刷新复用宿主会话，不写入文件。初始化重复请求共享结果，创建竞争会重新读取已有会话。
- 竖向 A4 采用 700×990 逻辑绘图尺寸，保持 210:297 比例，每毫米对应 10/3 个纸面单位。整页适配由中央区域可用宽、高共同决定；当前默认在此基础上放大至 175%，页首保持可见，水平居中，超出视口时可滚动。谱高采用常规分谱 7.03 mm 参考，全部符号与谱线在同一 SVG 内共同缩放。
- 初始空小节宽 18 个谱间距（约 31.64 mm），不撑满整行。后续小节按节拍、事件密度、附点和变音符号保留空间，空间不足换行、换页；每个系统重复谱号和拍号。
- 谱号、拍号和整小节休止符由同一 VexFlow SVG 绘制。空小节休止符仅是显示占位，不写入 Core，不增加撤销历史。
- 整小节全休止符在第四线下悬，二分休止符在第三线上托；复合拍使用对应拍号的连梁分组。停靠区收放或尺寸调整时重新适配纸张、清除横向偏移，处于页首时继续保持页首。长谱面可纵向滚动、中键平移。
- `NoteInputPanel` 接收显示属性及回调；`NoteInputComponent` 拥有独立外观和条件错误反馈。默认装配到左侧停靠区，通过公共宿主提供挂载、尺寸和焦点能力，不增加统一标题栏或输入开关。大音符和完整音名分区使用轻微不同的中性深灰底色；窄停靠区分行或收成图标入口。
- 初始四分音符，＋缩短一半，−延长一倍，范围为全至十六分音符；. 或按钮切换单附点。独立按钮选择降、还原、升号。休止工具用于鼠标追加，R 直接写入休止；重新输入音名恢复音符输入。
- A–G 生成草稿，组号 2–6 完成后才写入真实 Native 文档。点击小节定位末尾，双击按音高追加；末小节写满后由已有宿主能力增加空小节。菜单和 Ctrl+Z／Ctrl+Shift+Z 共用现有撤销重做入口。
- 工具和谱面共用本地 Bravura 字体加载及重试生命周期，工具符号按实际墨迹范围居中；附点与音符保持同一字体基线，音名中的升降号采用紧凑墨迹视口。参数和草稿不写入 Core；串行提交及不确定请求重试仍由已有编辑会话处理。
- 铅笔图标表示输入预览，指针表示当前选择，均提供悬停说明和无障碍名称。音名显示音名、升降记号及组号；未完成草稿显示 `A_`，不会借用上一音符的组号；首次进入和休止状态不伪造音高。最近输入音高仅由成功提交后投影中的事件 ID 解析，输入预览采用当前工具参数。
- 音名下方的分数表示占整个当前小节的比例，包含附点并精确约分，不再显示 `1/2 ·` 这类原时值加点的数字写法。4/4 的附点二分显示 `3/4`，3/4 的四分显示 `1/3`，6/8 的附点四分显示 `1/2`；满小节为 `1/1`。输入模式取目标小节拍号，选择模式取所选事件所在小节拍号；缺少拍号时不猜测比例。超过一小节的预览不强制截为 `1/1`，落谱合法性仍由 Native 判断。实际音符字形保留标准附点。
- 本轮音符组件动画遵循已读 Interface Design 的短时反馈指导：按钮按压缩至 0.97，悬停／选中叠层用 120 ms 淡入淡出，变音选择底块用 180 ms 移动，时值和音名变音符号用 100 ms 轻量显现；逻辑立即更新，没有动画等待、节流或提交延迟。公共宿主与谱面光标未增加动画。系统减少动态效果时关闭位移、缩放和符号显现动画，保留轻量透明度反馈。外部动画资料检索未返回可用内容，未将其作为本轮已核验依据。
- 点击真实音符或休止符选择后，框内显示当前投影中的真实属性。加减号、附点和变音作用于该选择，按音名键或 R 自动恢复输入并处理同一次按键；Esc 取消选择，←→ 移动选择。选中音符后 Backspace／Delete 改为等时值休止，末尾休止可以移除；中间休止保留拍位。休止按钮可把选中音符改为等时值休止，不猜测休止转音符所需的音高。
- 连接失败和绘图失败分别提供重试入口。无常驻小节位置／输入说明行，正常状态只有符号和属性；错误发生时才显示必要说明和重试。独立属性、文件和播放仍未装配；Backspace／Esc 在输入时取消草稿。连续输入会使当前插入位置保持可见。
- 上方停靠区将编辑历史置左、谱面缩放置右，并排显示两件明确配对的小工具；其他同区组件继续通过共享停靠区切换。撤销／重做按钮只读取真实会话历史深度，忙碌或连接受阻时禁用，点击、菜单和 Ctrl／⌘+Z／Ctrl／⌘+Shift+Z 共用同一次应用操作。缩放范围 75%–250%，Ctrl／⌘+0 适配整页；缩放不修改文档历史。

## 运行

在仓库根目录执行：

```powershell
npm.cmd --prefix apps/workbench ci
npm.cmd run ui:dev
```

打开 http://127.0.0.1:5173。构建与检查：

```powershell
npm.cmd run ui:build
npm.cmd run ui:typecheck
```

独立 package / lockfile 管理前端依赖。首次运行前需要安装仓库根目录依赖，并具备 `target/integrated-v2/brilliant_kernel_node.node`。dev、build、typecheck 自动将公开 Core 接口编译到本目录的 `.kernel/`；前端构建输出在本目录的 `dist/`，不改写根目录的 `dist/` 或 Native addon。

## C03 行为与边界

- 标题选填，去除首尾空白后最多 120 字符；留空使用“未命名乐谱”。
- 初始小节数默认 4，支持 1–128 的整数。这是当前界面限制，不是内核上限。
- 固定单谱表、单声部、高音谱号、4/4；创建空事件序列，不为展示而写入休止符。
- 错误在字段旁提示，保留输入；提交中阻止重复提交。创建失败保留原作品，重试相同请求不会重复创建。
- 已有作品时，必须勾选放弃当前作品才能替换；取消保留原作品。C09 接入保存后再扩展为完整保存／不保存／取消流程。
- 取消返回文件菜单触发器；创建成功聚焦工作区。初始化小节不会进入用户撤销历史。

目前会话只保存在本地宿主进程内存中；刷新页面可重新连接，宿主重启后丢失。sessionStorage 只保存工作区标识，不保存音乐文档。尚无文件持久化、自动保存或崩溃恢复；每个宿主进程暂限 32 个工作区，没有自动回收闲置工作区。

## C04 基础显示行为与边界

用户最新纠正：先完成基础能力，布局编辑操作后置。`WorkbenchPanel` 接收宿主尺寸并提供内容视口；默认只跟随工作区，不显示标题栏、声部信息、尺寸按钮或拖拽手柄。外层工作区透明，视觉上只有一层白色谱面。尺寸弹窗已移除；鼠标拖拽只保留未启用的内部接口，尚未完成交互验收，不宣称已经开放布局编辑。布局、尺寸和视口缩放与音乐文档分离。

已有 50%–200% 谱面缩放移至全局“视图”菜单，不增加常驻工具栏。页面刷新后使用默认尺寸和比例，尚未实现布局持久化。

- 显示真实文档的小节 ID、顺序、数量与拍号；绘制单谱表高音五线谱、谱号、小节线、编号、单音、休止符、单附点、升降还原号和基础连梁。
- 每行最多四小节，随容器宽度换行，末行保持与前面一致的小节宽度。每行重绘谱号；仅起始与变化位置显示拍号。
- 通过 ResizeObserver 适配容器宽度；谱面保持可读尺寸，长谱面在工作区纵向滚动。极窄容器保留 240px 最小绘图宽度，可横向滚动。
- 同一次内核原子读取生成摘要和显示投影，投影是可丢弃的只读数据。换行、滚动、绘图不会修改乐谱、脏状态或撤销历史。
- 绘图异步完成后只接纳当前文档的结果，组件销毁时清理观察器和绘图；出现绘制错误时显示可重试提示。
- 支持 C2–B6 单音、自然／升／降半音、全至十六分音符及单附点；另支持修改时值后用于补齐间隙的无附点三十二分休止。和弦、连音、弱起、扩展内容和其他编制明确提示暂不支持，不将已有音乐画成空白。
- 为短时值和高低加线保留排版空间，必要时减少每行小节数；输入光标自动滚入可见区域。VexFlow 的内联尺寸同步到真实缩放比例，鼠标坐标经 SVG 变换逆矩阵映射。
- VexFlow 5.0.0 仅存在于绘图适配层；使用带 Bravura／Academico 字体数据的本地包入口，首次绘谱时按需加载，不在运行时请求 CDN。当前绘图分块约 722 kB（gzip 388 kB），构建会提示超过 500 kB；尚未开展包体和长谱面性能优化。

## C05 输入与 C06 撤销重做

- 谱面下方是独立输入工具组件，不增加谱面标题栏或白色外卡片。`HistoryControls` 独立装配，可由宿主放到其他位置。
- 点击“开始输入”，选择时值、单附点和变音；先按 A–G 显示 `A_` 草稿，再按组号 2–6 提交，例如 `A4B4C5`。顶排数字与数字小键盘均可使用；数字不控制时值。工具参数只影响后续输入。
- 草稿不修改文档或历史；另一个音名替换草稿，Backspace 取消草稿，Esc 清空草稿并退出输入。非法组号保留草稿并提示，不自动补齐或超时提交；按键自动重复不产生新输入。
- R 按当前时值直接写入休止符并取消草稿；选择休止符工具后可双击谱面写入休止，重新按音名会切回音符输入。鼠标重新定位、历史操作和更换文档会取消草稿。时值与变音调整可保留草稿，提交时采用当前设置。
- 单击小节选择其当前内容末尾；双击以鼠标纵向位置确定音高并追加。单击已有音符／休止符会退出输入并选择该事件；属性改写通过 C07 显式应用，尚不支持任意拍插入。
- 每次成功输入按时值推进；小节恰好写满后进入下一小节。末小节满或剩余容量不足时拒绝并提示，不覆盖、挤动或自动拆分。暂不能自动添加小节。
- 撤销、重做按钮与编辑菜单共用真实 Native 历史；谱面聚焦时支持 Ctrl+Z／Ctrl+Shift+Z。撤销后输入会清除重做分支。
- 浏览器输入队列串行提交，采用文档标识、版本和请求标识保护。明确拒绝会停止后续队列；连接结果不确定时保留同一请求供重试确认。宿主缓存最近 64 次成功操作；较旧重试由版本冲突保护，不重复写入。
- 输入参数、目标、队列属于 UI 会话，不写入 ScoreDocument。浏览器只读取提交后投影和真实历史深度。

## C06 单事件选择与删除

- 单击音符／休止符显示局部高亮并退出输入，选择与输入位置分别保存。←→ 在事件之间移动选择；Esc 或“取消选择”清除选择。切回输入会清除选择。
- 选中音符后使用“删除音符”、编辑菜单或 Delete，将其替换为等时值休止符，后续音符拍位保持不变。宿主通过公开删除＋插入命令组成一个原子事务，一次撤销完整恢复原音符。
- 末尾休止符可以移除并释放小节尾部时值；中间休止符禁止移除，界面说明其用于保留节拍。尚不提供挤动后续事件的删除模式。
- 提交期间禁止改变选择和再次删除；失败保留选择与乐谱。事件被成功移除或更换文档后清除失效选择。缩放、选择、高亮本身不产生音乐历史。
- `useScoreSelection` 仅保存事件 ID，`SelectionControls` 呈现删除入口与选中说明；事件命中区域由绘图适配产生，界面不读取 VexFlow 内部对象。
- 本轮未接入多选、复制／剪切／粘贴或小节增删。C06 仍未全部完成。

## C07 属性侧边栏

- 固定右侧，可从“视图”菜单收起／展开；沿用灰色工作区背景，不增加谱面外卡片或标题栏。窗口宽度不超过 640px 时默认收起，按需以属性抽屉打开，支持 Tab 焦点约束、Esc 关闭与焦点返回。
- 未选择时显示简短提示和作品标题。选择音符后显示音名、组号、变音、时值、附点及只读小节／节拍；选择休止时不显示音高字段。
- 字段先形成 UI 草稿，点击“应用”才提交；“重置”恢复当前事件的已提交值。修改输入工具参数不改变已选音符。更换选择、收起属性栏或刷新会丢弃未应用草稿；修改另一类属性不会清除当前草稿。
- 音高、时值与附点一起修改使用一个公开 Core 批事务，一步撤销／重做。保留目标事件 ID，选择不会因属性修改丢失。作品标题独立提交，同样使用 Native 历史。
- 缩短中间事件时补齐休止；延长时仅使用紧随的休止与可用尾部空白，后续音符保持原拍位。覆盖后续音符或超出小节容量时拒绝整次修改，保留原谱面和待修正字段。
- 无附点三十二分休止可以显示和修改，用于精确保留附点十六分缩短后的间隙。仍不开放三十二分音符、附点三十二分休止或任意跨小节拆分。
- 属性错误只在当前可见入口显示一次，收起后由工具区承接；重试使用同一请求，不重复写入。修改成功后桌面侧栏将焦点返回谱面，抽屉则保持焦点在对话框内。
- `ScoreInspector` 管理字段草稿，`InspectorSlot` 管理响应式呈现；共用 `DurationSelect` 和 `AlterationSelect`，宿主通过 `prepareEventProperties` 组合公开命令，组件不导入 Core 或 VexFlow。

## 数据与绘图边界

- `NewScoreDialog` 管理表单、校验和焦点，通过回调请求创建，不导入内核。
- `WorkbenchClient` 管理浏览器到本地宿主的请求；React 只持有同版本会话摘要与只读显示投影。
- `ScoreSessionService` 管理真实内核会话，经公开 Core／SDK 接口与已有 Native 宿主适配入口创建文档、追加事件和撤销重做，不采用浏览器里的替代内核。
- `useScoreInput` 管理输入参数、目标和串行提交；`NoteInputTools` 负责控件呈现，`HistoryControls` 负责历史按钮，菜单使用同一操作回调。
- `workbenchApi` 将会话服务接入 Vite dev／preview。静态文件单独托管不足以运行该接口；此通道是当前本地开发宿主，不代表最终桌面应用架构。
- `projectNotation` 从公开的 ScoreDocument 快照生成显示投影，不依赖绘图库。
- `layoutStaff` 生成纯几何布局；`NotationView` 负责尺寸观察、加载／错误反馈与绘图生命周期；`NotationRenderer` 接口由应用装配为 VexFlow 实现，组件本身不导入 VexFlow。
- 工作台容器只装配内容，不引入谱面业务。帮助内容、全局快捷键和完整命令状态后续按能力逐步增加。

## UI 插件接口基础

UI 插件的最小职责类型为 `view`、`tool`、`inspector`。浮层不是第四种业务类型，而是 `inline`、`panel`、`popover`、`dialog` 之一的呈现方式；导航栏和工作台容器由宿主固定提供。`src/ui/plugin-contract.ts` 定义组件的插槽、呈现方式、布局能力、读取权限和命令权限，`src/ui/component-registry.ts` 负责注册、查询、卸载和生命周期实例。

插件通过 `UiComponentContext` 读取只读会话、选区、输入状态和布局上下文，通过 `UiCommandDispatcher` 请求操作。插件不直接导入 Native、Core 私有实现、文件系统或其他组件内部状态。文档创建／打开／保存／导出属于应用命令与宿主文件服务；它们可以由菜单、对话框等 UI 入口触发，但不作为普通工具组件重复实现。

第一批内置注册项为 `notation.staff-view`、`notation.note-input` 和 `notation.inspector`。工作台现在通过共享注册器查询这些角色后再装配对应 React 渲染器；注册器负责接口和权限边界，具体渲染仍由功能模块拥有。注册器测试覆盖内置角色顺序、重复 ID、非法插槽／呈现方式和实例更新／卸载。

## 组件边界

- `WorkbenchApp`：应用装配与命令回调。未提供回调的菜单命令不可执行。
- `WorkbenchShell`：固定导航、内容区域与可选的固定右侧属性槽。空属性槽不占空间；不保存音乐数据。
- `NavigationBar`：由类型明确的菜单数据渲染全局入口，使用 Radix Menubar 处理键盘、焦点与浮层定位。
- `WorkspaceSurface`：内容容器；接收子视图，不依赖某一种谱面或乐器。
- `AboutDialog`：辅助对话框，关闭后焦点回到帮助菜单。
- `styles/theme.css`：单一浅色主题的语义变量；圆角、间距、色彩统一管理。没有主题编辑器。

这些是内部组件接口，不是已发布的插件 ABI。后续功能通过装配入口接入；加载外部插件、自由停靠、持久化布局和新增谱面需独立设计。音乐修改必须经过内核公开接口，工作台不引入另一套文档或历史。
